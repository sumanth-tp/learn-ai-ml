# PyTorch Master Cheatsheet

PyTorch is the dominant deep learning framework. Master tensors, `nn.Module`,
autograd, optimizers, DataLoaders, and the training loop — these patterns apply
to every PyTorch project from a tiny MLP to LLaMA fine-tuning.

## Tensor creation

| Method                                     | Description                                                                                                             | Code example                                                                                                         |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `torch.tensor()`                           | `torch.tensor(data, dtype=None, device=None, requires_grad=False)` — Construct a tensor from a list/array. Copies data. | `import torch`<br/>`x = torch.tensor([[1, 2], [3, 4]], dtype=torch.float32)`<br/>`print(x.shape, x.dtype, x.device)` |
| `torch.zeros()` / `torch.ones()`           | `torch.zeros(*size, dtype=None, device=None, requires_grad=False)` / `torch.ones(*size, ...)` — Filled tensors.         | `z = torch.zeros(3, 4)`<br/>`o = torch.ones(2, 2, dtype=torch.int64)`                                                |
| `torch.full()`                             | `torch.full(size, fill_value, dtype=None, device=None)` — Tensor filled with a constant.                                | `mask = torch.full((2, 3), -1.0)`                                                                                    |
| `torch.arange()`                           | `torch.arange(start=0, end, step=1, dtype=None, device=None)` — Like Python's `range()`.                                | `print(torch.arange(0, 10, 2)) # tensor([0, 2, 4, 6, 8])`                                                            |
| `torch.linspace()`                         | `torch.linspace(start, end, steps, dtype=None, device=None)` — Evenly spaced floats, inclusive of both ends.            | `print(torch.linspace(0, 1, 5))`                                                                                     |
| `torch.eye()`                              | `torch.eye(n, m=None, dtype=None, device=None)` — Identity matrix.                                                      | `print(torch.eye(3))`                                                                                                |
| `torch.empty()`                            | `torch.empty(*size, dtype=None, device=None)` — Allocates without initializing. Fast when you'll overwrite.             | `buf = torch.empty(1000, dtype=torch.float32)`                                                                       |
| `torch.zeros_like()` / `torch.ones_like()` | `torch.zeros_like(input, dtype=None, device=None)` — Same shape/dtype/device as `input`.                                | `grad = torch.zeros_like(weights)`                                                                                   |
| `torch.randn()` / `torch.rand()`           | `torch.randn(*size)` (normal) / `torch.rand(*size)` (uniform [0,1)).                                                    | `x = torch.randn(3, 3)`<br/>`u = torch.rand(2, 5)`                                                                   |
| `torch.randint()`                          | `torch.randint(low=0, high, size, dtype=None, device=None)` — Random integers in `[low, high)`.                         | `idx = torch.randint(0, 100, (5,))`                                                                                  |
| `torch.from_numpy()`                       | `torch.from_numpy(ndarray)` — Zero-copy view of a NumPy array. Changes share memory.                                    | `import numpy as np`<br/>`a = np.array([1, 2, 3])`<br/>`t = torch.from_numpy(a)`                                     |
| `tensor.numpy()`                           | `tensor.numpy()` — Convert CPU tensor to NumPy. Tensor must be on CPU and detached.                                     | `arr = t.cpu().detach().numpy()`                                                                                     |

## Tensor properties and dtype

| Method               | Description                                                                                                                | Code example                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `.shape` / `.size()` | Attribute / `tensor.size(dim=None)` — Returns dimensions.                                                                  | `print(x.shape) # torch.Size([3, 4])`<br/>`print(x.size(0)) # 3`                 |
| `.dtype`             | Attribute. Element type.                                                                                                   | `print(x.dtype) # torch.float32`                                                 |
| `.device`            | Attribute. Where the tensor lives.                                                                                         | `print(x.device) # cuda:0 or cpu`                                                |
| `.to()`              | `tensor.to(device=None, dtype=None, non_blocking=False)` — Move and/or cast. Returns a new tensor unless already matching. | `x = x.to("cuda")`<br/>`x = x.to(dtype=torch.float16)`                           |
| `.cuda()` / `.cpu()` | `tensor.cuda(device=None, non_blocking=False)` / `tensor.cpu()` — Shortcuts for `.to()`.                                   | `x = x.cuda()`                                                                   |
| `.dim()` / `.ndim`   | Number of dimensions.                                                                                                      | `print(x.dim()) # 2`                                                             |
| `.numel()`           | Total element count.                                                                                                       | `print(x.numel()) # 12`                                                          |
| `.requires_grad_()`  | `tensor.requires_grad_(requires_grad=True)` — In-place toggle. Trailing underscore = in-place.                             | `w = torch.randn(3, requires_grad=True)`<br/>`# or`<br/>`w.requires_grad_(True)` |

## Tensor operations and broadcasting

| Method                                                | Description                                                                                                                 | Code example                                                                                            |
| ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Element-wise arithmetic                               | Operators `+`, `-`, `*`, `/`, `**` — Work element-wise with broadcasting.                                                   | `a = torch.tensor([1., 2., 3.])`<br/>`b = torch.tensor([10., 20., 30.])`<br/>`print(a + b, a * b)`      |
| Matrix multiplication                                 | `torch.matmul(a, b)` or `a @ b` — Batched matrix multiplication.                                                            | `A = torch.randn(2, 3, 4)`<br/>`B = torch.randn(2, 4, 5)`<br/>`print((A @ B).shape) # (2, 3, 5)`        |
| `torch.mm()` / `torch.bmm()`                          | `torch.mm(a, b)` (2D × 2D) / `torch.bmm(a, b)` (batched 3D × 3D).                                                           | `C = torch.mm(torch.randn(3, 4), torch.randn(4, 5))`                                                    |
| `tensor.sum()`                                        | `tensor.sum(dim=None, keepdim=False, dtype=None)` — Sum over dim(s) or all elements.                                        | `x = torch.tensor([[1., 2.], [3., 4.]])`<br/>`print(x.sum()) # 10`<br/>`print(x.sum(dim=0)) # [4, 6]`   |
| `tensor.mean()` / `.std()` / `.var()`                 | `mean(dim=None, keepdim=False)` / `std(dim=None, unbiased=True)` — Reductions.                                              | `print(x.mean(dim=0))`<br/>`print(x.std(dim=0, unbiased=False))`                                        |
| `tensor.max()` / `.min()` / `.argmax()` / `.argmin()` | `max(dim=None, keepdim=False)` → returns `(values, indices)`. `argmax(dim=None)` → indices only.                            | `logits = torch.randn(8, 10)`<br/>`pred = logits.argmax(dim=-1)`                                        |
| `torch.exp()` / `torch.log()` / `torch.sqrt()`        | `torch.exp(input)` / `torch.log(input)` / `torch.sqrt(input)` — Element-wise.                                               | `print(torch.exp(torch.tensor([0., 1.])))`                                                              |
| `torch.softmax()`                                     | `torch.softmax(input, dim, dtype=None)` — Numerically stable softmax along `dim`.                                           | `probs = torch.softmax(logits, dim=-1)`                                                                 |
| `torch.log_softmax()`                                 | `torch.log_softmax(input, dim)` — Faster + more stable than `log(softmax(x))`. Pair with `nll_loss`.                        | `log_probs = torch.log_softmax(logits, dim=-1)`                                                         |
| `torch.clamp()`                                       | `torch.clamp(input, min=None, max=None)` — Clip values to range.                                                            | `x = torch.clamp(x, min=0., max=1.)`                                                                    |
| `torch.cat()`                                         | `torch.cat(tensors, dim=0)` — Concatenate along existing dim. Shapes must match except in `dim`.                            | `out = torch.cat([a, b], dim=0)`                                                                        |
| `torch.stack()`                                       | `torch.stack(tensors, dim=0)` — Stack along a NEW dim.                                                                      | `batch = torch.stack([img1, img2, img3], dim=0)`                                                        |
| `tensor.view()` / `.reshape()`                        | `tensor.view(*shape)` (contiguous required) / `tensor.reshape(*shape)` (handles non-contiguous). Use `-1` for inferred dim. | `x = torch.randn(2, 3, 4)`<br/>`print(x.view(6, 4).shape)`<br/>`print(x.reshape(-1, 4).shape)`          |
| `tensor.permute()` / `.transpose()`                   | `tensor.permute(*dims)` (reorder all dims) / `tensor.transpose(dim0, dim1)` (swap two dims).                                | `x = torch.randn(2, 3, 4)`<br/>`y = x.permute(2, 0, 1) # (4, 2, 3)`                                     |
| `tensor.squeeze()` / `.unsqueeze()`                   | `tensor.squeeze(dim=None)` (remove size-1 dims) / `tensor.unsqueeze(dim)` (insert size-1 dim).                              | `x = torch.randn(1, 3, 1, 5)`<br/>`print(x.squeeze().shape) # (3, 5)`<br/>`print(x.unsqueeze(0).shape)` |
| `tensor.expand()` / `.repeat()`                       | `tensor.expand(*sizes)` (memory-free broadcast) / `tensor.repeat(*sizes)` (allocate copies).                                | `x = torch.tensor([[1.], [2.]])`<br/>`print(x.expand(2, 3))`                                            |

## Indexing and slicing

| Method                  | Description                                                                                        | Code example                                                                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Basic indexing          | Syntax: `t[i, j]`, `t[:, k]`, `t[i:j]`. Same as NumPy.                                             | `x = torch.arange(12).reshape(3, 4)`<br/>`print(x[1, 2]) # 6`                                                                           |
| Boolean masking         | `t[mask]` where `mask` is a bool tensor of the same shape.                                         | `x = torch.tensor([1, -2, 3, -4])`<br/>`print(x[x > 0]) # [1, 3]`                                                                       |
| Fancy indexing          | `t[index_tensor]` — Pick rows/cols by index tensor.                                                | `x = torch.arange(10) ** 2`<br/>`print(x[torch.tensor([1, 3, 7])])`                                                                     |
| `torch.where()`         | `torch.where(condition, input, other)` — Element-wise `if/else`.                                   | `clipped = torch.where(x > 0, x, torch.zeros_like(x))`                                                                                  |
| `torch.gather()`        | `torch.gather(input, dim, index)` — Gather along an axis using an index tensor. Common in seq2seq. | `logits = torch.randn(4, 10)`<br/>`labels = torch.tensor([2, 5, 1, 8])`<br/>`scores = logits.gather(1, labels.unsqueeze(1)).squeeze(1)` |
| `torch.masked_select()` | `torch.masked_select(input, mask)` — Returns 1D tensor of elements where mask is True.             | `print(torch.masked_select(x, x > 0))`                                                                                                  |
| `tensor.scatter_()`     | `tensor.scatter_(dim, index, src)` — In-place scatter. Useful for one-hot encoding.                | `one_hot = torch.zeros(4, 10).scatter_(1, labels.unsqueeze(1), 1.0)`                                                                    |

## Autograd

| Method                     | Description                                                                                                                                       | Code example                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `requires_grad=True`       | Mark a tensor as a leaf parameter; autograd will track ops on it.                                                                                 | `w = torch.randn(3, requires_grad=True)`                                |
| `.backward()`              | `tensor.backward(gradient=None, retain_graph=False, create_graph=False)` — Compute gradients of `tensor` (a scalar) w.r.t. all leaf tensors.      | `loss = ((w - 1) ** 2).sum()`<br/>`loss.backward()`<br/>`print(w.grad)` |
| `.grad`                    | Attribute populated after `.backward()`. Accumulates — zero between steps.                                                                        | `optimizer.zero_grad()`                                                 |
| `torch.no_grad()`          | Context manager: `with torch.no_grad(): ...`. Disables grad tracking. Use for inference, eval, or saving memory.                                  | `with torch.no_grad():`<br/>` logits = model(x)`                        |
| `tensor.detach()`          | `tensor.detach()` — Returns a new tensor sharing data but without grad tracking.                                                                  | `target = target_net(x).detach()`                                       |
| `torch.autograd.grad()`    | `torch.autograd.grad(outputs, inputs, grad_outputs=None, retain_graph=False, create_graph=False)` — Compute gradients without populating `.grad`. | `grads = torch.autograd.grad(loss, params)`                             |
| `torch.enable_grad()`      | Context manager: `with torch.enable_grad(): ...`. Force enable grad (nested inside `no_grad`).                                                    | `with torch.enable_grad(): loss.backward()`                             |
| `torch.set_grad_enabled()` | `torch.set_grad_enabled(mode)` — Toggle grad. Useful in train/eval logic.                                                                         | `torch.set_grad_enabled(model.training)`                                |

## nn.Module: building models

| Method                                      | Description                                                                                                                                | Code example                                                                                                                                                                                                                                                                                            |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nn.Module` subclassing                     | Inherit from `nn.Module`, define `__init__` (call `super().__init__()`) and `forward(self, ...)`.                                          | `import torch.nn as nn`<br/>`class MLP(nn.Module):`<br/>` def __init__(self, in_dim, hidden, out_dim):`<br/>` super().__init__()`<br/>` self.fc1 = nn.Linear(in_dim, hidden)`<br/>` self.fc2 = nn.Linear(hidden, out_dim)`<br/>` def forward(self, x):`<br/>` return self.fc2(torch.relu(self.fc1(x)))` |
| `nn.Linear`                                 | `nn.Linear(in_features, out_features, bias=True, device=None, dtype=None)` — Fully connected layer.                                        | `fc = nn.Linear(128, 64)`                                                                                                                                                                                                                                                                               |
| `nn.Conv2d`                                 | `nn.Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0, dilation=1, groups=1, bias=True)`.                                 | `conv = nn.Conv2d(3, 16, kernel_size=3, padding=1)`                                                                                                                                                                                                                                                     |
| `nn.BatchNorm1d` / `BatchNorm2d`            | `nn.BatchNorm2d(num_features, eps=1e-05, momentum=0.1, affine=True, track_running_stats=True)`.                                            | `bn = nn.BatchNorm2d(16)`                                                                                                                                                                                                                                                                               |
| `nn.LayerNorm`                              | `nn.LayerNorm(normalized_shape, eps=1e-05, elementwise_affine=True)` — Standard in transformers.                                           | `ln = nn.LayerNorm(768)`                                                                                                                                                                                                                                                                                |
| `nn.Dropout`                                | `nn.Dropout(p=0.5, inplace=False)` — Active in training mode only.                                                                         | `drop = nn.Dropout(p=0.1)`                                                                                                                                                                                                                                                                              |
| `nn.ReLU` / `nn.GELU` / `nn.SiLU`           | Activation modules. Use `nn.<Activation>()` or the functional form `F.relu(x)`, `F.gelu(x)`.                                               | `act = nn.GELU()`                                                                                                                                                                                                                                                                                       |
| `nn.Embedding`                              | `nn.Embedding(num_embeddings, embedding_dim, padding_idx=None)` — Vocab → vector lookup.                                                   | `emb = nn.Embedding(30522, 768)`                                                                                                                                                                                                                                                                        |
| `nn.MultiheadAttention`                     | `nn.MultiheadAttention(embed_dim, num_heads, dropout=0.0, bias=True, batch_first=False)`.                                                  | `mha = nn.MultiheadAttention(512, 8, batch_first=True)`                                                                                                                                                                                                                                                 |
| `nn.Sequential`                             | `nn.Sequential(*args)` — Chain modules. Calls them in order.                                                                               | `net = nn.Sequential(nn.Linear(10, 20), nn.ReLU(), nn.Linear(20, 1))`                                                                                                                                                                                                                                   |
| `nn.ModuleList` / `nn.ModuleDict`           | `nn.ModuleList(modules=None)` / `nn.ModuleDict(modules=None)` — Containers that register parameters (regular Python lists/dicts don't).    | `self.layers = nn.ModuleList([nn.Linear(64, 64) for _ in range(6)])`                                                                                                                                                                                                                                    |
| `model.parameters()`                        | `model.parameters(recurse=True)` — Iterator over parameters, for optimizers.                                                               | `for p in model.parameters():`<br/>` print(p.shape)`                                                                                                                                                                                                                                                    |
| `model.named_parameters()`                  | `model.named_parameters(prefix='', recurse=True)` — Yields `(name, param)`.                                                                | `for name, p in model.named_parameters():`<br/>` if "bias" in name: print(name)`                                                                                                                                                                                                                        |
| `model.state_dict()` / `.load_state_dict()` | `model.state_dict(destination=None, prefix='', keep_vars=False)` / `model.load_state_dict(state_dict, strict=True)` — Save / load weights. | `torch.save(model.state_dict(), "weights.pt")`<br/>`model.load_state_dict(torch.load("weights.pt"))`                                                                                                                                                                                                    |
| `model.train()` / `model.eval()`            | Toggle training mode. Affects `nn.Dropout` and `nn.BatchNorm`.                                                                             | `model.train() # for training`<br/>`model.eval() # for inference`                                                                                                                                                                                                                                       |

## Loss functions

| Method                          | Description                                                                                                                       | Code example                                                                                                     |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `nn.CrossEntropyLoss`           | `nn.CrossEntropyLoss(weight=None, ignore_index=-100, reduction='mean', label_smoothing=0.0)` — Takes raw logits + integer labels. | `criterion = nn.CrossEntropyLoss(ignore_index=-100, label_smoothing=0.1)`<br/>`loss = criterion(logits, labels)` |
| `nn.BCEWithLogitsLoss`          | `nn.BCEWithLogitsLoss(weight=None, reduction='mean', pos_weight=None)` — Binary cross-entropy with logits (numerically stable).   | `criterion = nn.BCEWithLogitsLoss(pos_weight=torch.tensor([3.0]))`                                               |
| `nn.MSELoss`                    | `nn.MSELoss(reduction='mean')` — Mean squared error for regression.                                                               | `criterion = nn.MSELoss()`                                                                                       |
| `nn.L1Loss`                     | `nn.L1Loss(reduction='mean')` — Mean absolute error. More robust to outliers.                                                     | `criterion = nn.L1Loss()`                                                                                        |
| `nn.SmoothL1Loss` / `HuberLoss` | `nn.HuberLoss(reduction='mean', delta=1.0)` — Quadratic near 0, linear far from 0. Common in RL/detection.                        | `criterion = nn.HuberLoss(delta=1.0)`                                                                            |
| `nn.NLLLoss`                    | `nn.NLLLoss(weight=None, ignore_index=-100, reduction='mean')` — Pair with `log_softmax` outputs.                                 | `loss = nn.NLLLoss()(log_probs, labels)`                                                                         |
| `nn.KLDivLoss`                  | `nn.KLDivLoss(reduction='batchmean', log_target=False)` — KL divergence. Inputs should be log-probabilities.                      | `criterion = nn.KLDivLoss(reduction="batchmean")`                                                                |
| `F.cross_entropy`               | Functional form: `F.cross_entropy(input, target, weight=None, ignore_index=-100, reduction='mean')`.                              | `import torch.nn.functional as F`<br/>`loss = F.cross_entropy(logits, labels)`                                   |

## Optimizers and schedulers

| Method                  | Description                                                                                                                    | Code example                                                                                                         |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| `torch.optim.SGD`       | `SGD(params, lr, momentum=0, weight_decay=0, nesterov=False)`.                                                                 | `opt = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)`                                                   |
| `torch.optim.Adam`      | `Adam(params, lr=1e-3, betas=(0.9, 0.999), eps=1e-08, weight_decay=0)`.                                                        | `opt = torch.optim.Adam(model.parameters(), lr=3e-4)`                                                                |
| `torch.optim.AdamW`     | `AdamW(params, lr=1e-3, betas=(0.9, 0.999), eps=1e-08, weight_decay=0.01)` — Decoupled weight decay. Default for transformers. | `opt = torch.optim.AdamW(model.parameters(), lr=5e-5, weight_decay=0.01)`                                            |
| `optimizer.zero_grad()` | `optimizer.zero_grad(set_to_none=True)` — Reset gradients between steps. `set_to_none=True` is faster.                         | `optimizer.zero_grad()`                                                                                              |
| `optimizer.step()`      | Applies the accumulated gradients to update parameters.                                                                        | `loss.backward()`<br/>`optimizer.step()`                                                                             |
| `LR Scheduler: StepLR`  | `StepLR(optimizer, step_size, gamma=0.1)` — Multiply LR by `gamma` every `step_size` epochs.                                   | `from torch.optim.lr_scheduler import StepLR`<br/>`scheduler = StepLR(opt, step_size=10, gamma=0.5)`                 |
| `CosineAnnealingLR`     | `CosineAnnealingLR(optimizer, T_max, eta_min=0)` — Cosine schedule. Common for training transformers from scratch.             | `from torch.optim.lr_scheduler import CosineAnnealingLR`<br/>`scheduler = CosineAnnealingLR(opt, T_max=total_steps)` |
| `OneCycleLR`            | `OneCycleLR(optimizer, max_lr, total_steps=None, epochs=None, steps_per_epoch=None, pct_start=0.3)` — Warmup + cosine decay.   | `scheduler = OneCycleLR(opt, max_lr=1e-3, total_steps=total_steps)`                                                  |
| `ReduceLROnPlateau`     | `ReduceLROnPlateau(optimizer, mode='min', factor=0.1, patience=10, threshold=1e-4)` — Reduce when metric stops improving.      | `scheduler.step(val_loss) # called per epoch with metric`                                                            |
| Gradient clipping       | `torch.nn.utils.clip_grad_norm_(parameters, max_norm, norm_type=2.0)` — Clip gradient norms in-place.                          | `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)`                                                   |

## Datasets and DataLoaders

| Method                  | Description                                                                                                                                      | Code example                                                                                                                                                                                                                                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Dataset` subclass      | Inherit `torch.utils.data.Dataset`. Implement `__len__(self) -> int` and `__getitem__(self, idx)`.                                               | `from torch.utils.data import Dataset`<br/>`class MyDataset(Dataset):`<br/>` def __init__(self, X, y):`<br/>` self.X = torch.tensor(X, dtype=torch.float32)`<br/>` self.y = torch.tensor(y, dtype=torch.long)`<br/>` def __len__(self): return len(self.X)`<br/>` def __getitem__(self, idx): return self.X[idx], self.y[idx]` |
| `DataLoader`            | `DataLoader(dataset, batch_size=1, shuffle=False, num_workers=0, pin_memory=False, drop_last=False, collate_fn=None, persistent_workers=False)`. | `from torch.utils.data import DataLoader`<br/>`loader = DataLoader(ds, batch_size=64, shuffle=True, num_workers=4, pin_memory=True)`                                                                                                                                                                                           |
| `TensorDataset`         | `TensorDataset(*tensors)` — Wraps tensors aligned by first dim.                                                                                  | `from torch.utils.data import TensorDataset`<br/>`ds = TensorDataset(X_tensor, y_tensor)`                                                                                                                                                                                                                                      |
| `random_split()`        | `random_split(dataset, lengths, generator=None)` — Split dataset into non-overlapping parts.                                                     | `from torch.utils.data import random_split`<br/>`train, val = random_split(ds, [0.8, 0.2])`                                                                                                                                                                                                                                    |
| `Subset`                | `Subset(dataset, indices)` — Dataset view over a subset of indices.                                                                              | `from torch.utils.data import Subset`<br/>`train = Subset(ds, train_indices)`                                                                                                                                                                                                                                                  |
| Custom `collate_fn`     | `collate_fn(batch) -> batched_tensors` — Convert list of samples to a batch. Used for variable-length data.                                      | `def collate(batch):`<br/>` xs, ys = zip(*batch)`<br/>` return torch.stack(xs), torch.tensor(ys)`                                                                                                                                                                                                                              |
| `WeightedRandomSampler` | `WeightedRandomSampler(weights, num_samples, replacement=True)` — Oversample minority classes.                                                   | `from torch.utils.data import WeightedRandomSampler`<br/>`sampler = WeightedRandomSampler(class_weights[labels], len(labels))`                                                                                                                                                                                                 |

## The training loop

| Method                     | Description                                                                                                                         | Code example                                                                                                                                                                                                                                                        |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Standard training loop     | Forward pass → loss → backward → optimizer step.                                                                                    | `model.train()`<br/>`for epoch in range(epochs):`<br/>` for X, y in train_loader:`<br/>` X, y = X.to(device), y.to(device)`<br/>` optimizer.zero_grad()`<br/>` logits = model(X)`<br/>` loss = criterion(logits, y)`<br/>` loss.backward()`<br/>` optimizer.step()` |
| Validation loop            | `model.eval()` + `with torch.no_grad():` for inference passes.                                                                      | `model.eval()`<br/>`with torch.no_grad():`<br/>` for X, y in val_loader:`<br/>` logits = model(X.to(device))`<br/>` acc = (logits.argmax(-1) == y.to(device)).float().mean()`                                                                                       |
| Mixed precision (autocast) | `torch.amp.autocast(device_type, dtype=torch.float16, enabled=True)` — Run forward in lower precision.                              | `from torch.amp import autocast, GradScaler`<br/>`scaler = GradScaler()`<br/>`with autocast(device_type="cuda", dtype=torch.bfloat16):`<br/>` logits = model(X)`<br/>` loss = criterion(logits, y)`                                                                 |
| `GradScaler` (FP16)        | `GradScaler(init_scale=2.**16, growth_factor=2.0, backoff_factor=0.5, growth_interval=2000)` — Scales loss to avoid FP16 underflow. | `scaler.scale(loss).backward()`<br/>`scaler.step(optimizer)`<br/>`scaler.update()`                                                                                                                                                                                  |
| Gradient accumulation      | Accumulate grads over N micro-batches before stepping.                                                                              | `loss = criterion(logits, y) / accum_steps`<br/>`loss.backward()`<br/>`if (i + 1) % accum_steps == 0:`<br/>` optimizer.step()`<br/>` optimizer.zero_grad()`                                                                                                         |
| Save / load checkpoints    | `torch.save(obj, f)` / `torch.load(f, map_location=None)`. Save state dicts, not the model object.                                  | `torch.save({`<br/>` "model": model.state_dict(),`<br/>` "optim": optimizer.state_dict(),`<br/>` "epoch": epoch,`<br/>`}, "ckpt.pt")`                                                                                                                               |
| Set device                 | `device = torch.device("cuda" if torch.cuda.is_available() else "cpu")`.                                                            | `model = model.to(device)`                                                                                                                                                                                                                                          |
| Reproducibility            | `torch.manual_seed(seed)` and `torch.cuda.manual_seed_all(seed)`. Also set `torch.backends.cudnn.deterministic = True`.             | `torch.manual_seed(42)`<br/>`torch.cuda.manual_seed_all(42)`                                                                                                                                                                                                        |

## GPU and distributed

| Method                      | Description                                                                                                         | Code example                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `torch.cuda.is_available()` | Check if CUDA is usable.                                                                                            | `print(torch.cuda.is_available())`                                                                                  |
| `torch.cuda.device_count()` | Number of visible GPUs.                                                                                             | `print(torch.cuda.device_count())`                                                                                  |
| `torch.cuda.empty_cache()`  | Releases unused cached memory (doesn't free PyTorch's allocator).                                                   | `torch.cuda.empty_cache()`                                                                                          |
| `nn.DataParallel` (legacy)  | `nn.DataParallel(module, device_ids=None, output_device=None)` — Simple multi-GPU. Slower than DDP.                 | `model = nn.DataParallel(model)`                                                                                    |
| `DistributedDataParallel`   | `DDP(module, device_ids=None, output_device=None, find_unused_parameters=False)` — Production multi-GPU.            | `from torch.nn.parallel import DistributedDataParallel as DDP`<br/>`model = DDP(model.to(rank), device_ids=[rank])` |
| `torch.compile()` (2.0+)    | `torch.compile(model, mode='default', dynamic=False, fullgraph=False, backend='inductor')` — JIT-compile for speed. | `model = torch.compile(model)`                                                                                      |
| `non_blocking=True`         | Argument to `.to()` and `.cuda()`. Async transfer with `pin_memory=True` DataLoader.                                | `X = X.to(device, non_blocking=True)`                                                                               |

## Common patterns

| Pattern                          | Code                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Full MLP + train loop            | `class MLP(nn.Module):`<br/>` def __init__(self):`<br/>` super().__init__()`<br/>` self.net = nn.Sequential(nn.Linear(784, 256), nn.ReLU(), nn.Dropout(0.2), nn.Linear(256, 10))`<br/>` def forward(self, x): return self.net(x)`<br/>`model = MLP().to(device)`<br/>`opt = torch.optim.AdamW(model.parameters(), lr=1e-3)`<br/>`criterion = nn.CrossEntropyLoss()` |
| Move batch to GPU                | `def to_device(batch, device):`<br/>` return {k: v.to(device, non_blocking=True) for k, v in batch.items()}`                                                                                                                                                                                                                                                        |
| Compute accuracy                 | `acc = (logits.argmax(dim=-1) == labels).float().mean().item()`                                                                                                                                                                                                                                                                                                     |
| Save best model                  | `if val_loss < best:`<br/>` best = val_loss`<br/>` torch.save(model.state_dict(), "best.pt")`                                                                                                                                                                                                                                                                       |
| Load weights skipping mismatches | `missing, unexpected = model.load_state_dict(torch.load("ckpt.pt"), strict=False)`                                                                                                                                                                                                                                                                                  |
| Freeze layers                    | `for p in model.encoder.parameters():`<br/>` p.requires_grad_(False)`                                                                                                                                                                                                                                                                                               |
| Count parameters                 | `print(sum(p.numel() for p in model.parameters() if p.requires_grad))`                                                                                                                                                                                                                                                                                              |
| Custom dataset for images        | `class ImageDataset(Dataset):`<br/>` def __init__(self, paths, labels, transform):`<br/>` self.paths = paths; self.labels = labels; self.transform = transform`<br/>` def __len__(self): return len(self.paths)`<br/>` def __getitem__(self, i):`<br/>` img = Image.open(self.paths[i]).convert("RGB")`<br/>` return self.transform(img), self.labels[i]`           |
| Inference in batches             | `model.eval()`<br/>`preds = []`<br/>`with torch.no_grad():`<br/>` for X, _ in loader:`<br/>` preds.append(model(X.to(device)).argmax(-1).cpu())`<br/>`preds = torch.cat(preds)`                                                                                                                                                                                     |
| Export to TorchScript            | `scripted = torch.jit.script(model)`<br/>`scripted.save("model.pt")`                                                                                                                                                                                                                                                                                                |
| Export to ONNX                   | `dummy = torch.randn(1, 3, 224, 224)`<br/>`torch.onnx.export(model, dummy, "model.onnx", input_names=["input"], output_names=["output"], dynamic_axes={"input": {0: "batch"}})`                                                                                                                                                                                     |
