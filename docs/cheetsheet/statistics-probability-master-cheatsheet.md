# Statistics and Probability Master Cheatsheet

Statistics underpins every ML model: how to summarize data, quantify
uncertainty, compare hypotheses, and avoid being fooled by your own results.
Covers descriptive stats, distributions, inference, A/B testing, Bayesian
basics, and ML-specific metrics — with `numpy`, `scipy.stats`, and `statsmodels`
APIs.

## Descriptive statistics

| Method                          | Description                                                                                                                                                                    | Code example                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| Mean                            | `np.mean(a, axis=None, dtype=None, keepdims=False)` — Arithmetic average. Sensitive to outliers; use median for heavy-tailed data.                                             | `import numpy as np`<br/>`values = np.array([1, 2, 3, 100])`<br/>`print(values.mean()) # 26.5` |
| Median                          | `np.median(a, axis=None, keepdims=False)` — Middle value. Robust to outliers.                                                                                                  | `print(np.median(values)) # 2.5`                                                               |
| Mode                            | `from scipy.stats import mode`<br/>`mode(a, axis=0, keepdims=False)` — Most common value.                                                                                      | `from scipy.stats import mode`<br/>`print(mode([1, 2, 2, 3, 3, 3]).mode) # 3`                  |
| Variance                        | `np.var(a, axis=None, ddof=0, keepdims=False)` — Average squared deviation. Use `ddof=1` for _sample_ variance (unbiased).                                                     | `print(np.var(values, ddof=1)) # ~2400.9`                                                      |
| Standard deviation              | `np.std(a, axis=None, ddof=0, keepdims=False)` — Square root of variance; same units as data.                                                                                  | `print(np.std(values, ddof=1))`                                                                |
| Range                           | `np.ptp(a, axis=None)` — Peak-to-peak: `max - min`.                                                                                                                            | `print(np.ptp(values)) # 99`                                                                   |
| Percentile / Quantile           | `np.percentile(a, q, axis=None)` (q in [0,100]) / `np.quantile(a, q, axis=None)` (q in [0,1]).                                                                                 | `print(np.quantile(values, [0.25, 0.5, 0.75]))`                                                |
| IQR                             | `from scipy.stats import iqr`<br/>`iqr(x, axis=None, rng=(25, 75))` — Interquartile range = Q3 − Q1. Robust spread measure.                                                    | `from scipy.stats import iqr`<br/>`print(iqr(values))`                                         |
| Covariance                      | `np.cov(m, y=None, rowvar=True, bias=False, ddof=None)` — Joint variation. `rowvar=False` if rows are observations.                                                            | `cov = np.cov(x, y, ddof=1)`<br/>`print(cov[0, 1])`                                            |
| Correlation (Pearson)           | `np.corrcoef(x, y=None)` — Returns correlation matrix. `r ∈ [-1, 1]`. Captures linear relationships only.                                                                      | `print(np.corrcoef(x, y)[0, 1])`                                                               |
| Correlation (Spearman)          | `from scipy.stats import spearmanr`<br/>`spearmanr(a, b=None, axis=0, alternative='two-sided')` — Rank correlation. Robust to outliers and non-linear monotonic relationships. | `from scipy.stats import spearmanr`<br/>`rho, p = spearmanr(x, y)`                             |
| Correlation (Kendall)           | `from scipy.stats import kendalltau`<br/>`kendalltau(x, y, alternative='two-sided')` — Concordant/discordant pair count. Strong for small samples.                             | `tau, p = kendalltau(x, y)`                                                                    |
| Skewness                        | `from scipy.stats import skew`<br/>`skew(a, axis=0, bias=True)` — Symmetry measure. Positive values mean right tail; negative values mean left tail; zero means symmetric.        | `from scipy.stats import skew, kurtosis`<br/>`print(skew(values))`                             |
| Kurtosis                        | `from scipy.stats import kurtosis`<br/>`kurtosis(a, axis=0, fisher=True, bias=True)` — Tail heaviness. Fisher's definition: normal = 0.                                        | `print(kurtosis(values))`                                                                      |
| Z-score                         | `(x - x.mean()) / x.std(ddof=1)` (manual) or `from scipy.stats import zscore` — Standardize to mean 0, std 1.                                                                  | `z = (x - x.mean()) / x.std(ddof=1)`                                                           |
| MAD (median absolute deviation) | `from scipy.stats import median_abs_deviation`<br/>`median_abs_deviation(x, axis=0, scale='normal')` — Robust spread alternative to std.                                       | `from scipy.stats import median_abs_deviation`<br/>`print(median_abs_deviation(values))`       |
| Five-number summary             | `np.quantile(x, [0, 0.25, 0.5, 0.75, 1.0])` — Min, Q1, median, Q3, max. The foundation of a box plot.                                                                          | `print(np.quantile(values, [0, 0.25, 0.5, 0.75, 1.0]))`                                        |

## Probability distributions (scipy.stats)

| Distribution               | Description                                                                                                                                               | Code example                                                                                                                        |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Bernoulli                  | `bernoulli(p)` — Binary outcome with success probability `p`. PMF: `bernoulli.pmf(k, p)`.                                                                 | `from scipy.stats import bernoulli`<br/>`samples = bernoulli.rvs(p=0.7, size=1000)`<br/>`print(bernoulli.pmf(1, p=0.7)) # 0.7`      |
| Binomial                   | `binom(n, p)` — Number of successes in `n` Bernoulli trials. `binom.pmf(k, n, p)`.                                                                        | `from scipy.stats import binom`<br/>`samples = binom.rvs(n=10, p=0.3, size=1000)`<br/>`print(binom.pmf(3, n=10, p=0.3))`            |
| Poisson                    | `poisson(mu)` — Event count in fixed interval with rate `mu`. `poisson.pmf(k, mu)`.                                                                       | `from scipy.stats import poisson`<br/>`samples = poisson.rvs(mu=4, size=1000)`<br/>`print(poisson.cdf(5, mu=4))`                    |
| Geometric                  | `geom(p)` — Number of trials until first success.                                                                                                         | `from scipy.stats import geom`<br/>`samples = geom.rvs(p=0.2, size=1000)`                                                           |
| Negative binomial          | `nbinom(n, p)` — Number of failures before `n` successes.                                                                                                 | `from scipy.stats import nbinom`<br/>`samples = nbinom.rvs(n=5, p=0.3, size=1000)`                                                  |
| Multinomial                | `multinomial(n, p)` — Counts across multiple categories.                                                                                                  | `from scipy.stats import multinomial`<br/>`samples = multinomial.rvs(n=20, p=[0.2, 0.5, 0.3], size=10)`                             |
| Normal (Gaussian)          | `norm(loc=0, scale=1)` — Bell curve. `norm.pdf(x, loc, scale)`, `norm.cdf(x, loc, scale)`.                                                                | `from scipy.stats import norm`<br/>`samples = norm.rvs(loc=0, scale=1, size=1000)`<br/>`print(norm.ppf(0.975)) # ~1.96`             |
| Uniform                    | `uniform(loc=0, scale=1)` — Equal probability in `[loc, loc+scale]`.                                                                                      | `from scipy.stats import uniform`<br/>`samples = uniform.rvs(loc=0, scale=10, size=1000)`                                           |
| Exponential                | `expon(scale=1)` — Waiting time between Poisson events. `scale = 1/rate`.                                                                                 | `from scipy.stats import expon`<br/>`samples = expon.rvs(scale=2, size=1000)`                                                       |
| Gamma                      | `gamma(a, scale=1)` — Generalized waiting time; sum of exponentials.                                                                                      | `from scipy.stats import gamma`<br/>`samples = gamma.rvs(a=2, scale=2, size=1000)`                                                  |
| Beta                       | `beta(a, b)` — Distribution on [0, 1]. Conjugate prior for Bernoulli/Binomial.                                                                            | `from scipy.stats import beta`<br/>`samples = beta.rvs(a=2, b=5, size=1000)`                                                        |
| Chi-square                 | `chi2(df)` — Sum of squared standard normals. Test statistic distribution.                                                                                | `from scipy.stats import chi2`<br/>`crit = chi2.ppf(0.95, df=5)`                                                                    |
| Student's t                | `t(df)` — Mean estimate when std is unknown. Heavier tails than normal at low `df`.                                                                       | `from scipy.stats import t`<br/>`samples = t.rvs(df=10, size=1000)`                                                                 |
| F                          | `f(dfn, dfd)` — Ratio of two chi-square variables. Used in ANOVA.                                                                                         | `from scipy.stats import f`<br/>`crit = f.ppf(0.95, dfn=3, dfd=20)`                                                                 |
| Log-normal                 | `lognorm(s, scale=np.exp(mu))` — Variable whose log is normal. Common for incomes, file sizes.                                                            | `from scipy.stats import lognorm`<br/>`samples = lognorm.rvs(s=0.5, scale=np.exp(1), size=1000)`                                    |
| Multivariate normal        | `from scipy.stats import multivariate_normal`<br/>`multivariate_normal(mean, cov)` — Vector Gaussian.                                                     | `from scipy.stats import multivariate_normal`<br/>`samples = multivariate_normal.rvs(mean=[0,0], cov=[[1,0.5],[0.5,1]], size=1000)` |
| Distribution methods (all) | `.pdf(x, *args)` (continuous) / `.pmf(x, *args)` (discrete) / `.cdf(x)` / `.sf(x) = 1-cdf` / `.ppf(q)` (inverse CDF) / `.rvs(*args, size, random_state)`. | `print(norm.pdf(0)) # density at x=0`<br/>`print(norm.cdf(1.96)) # P(X <= 1.96)`<br/>`print(norm.ppf(0.95)) # x s.t. P(X<=x)=0.95`  |

## Sampling and Monte Carlo

| Method                    | Description                                                                                                       | Code example                                                                                                                                                                                                                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `np.random.default_rng()` | `np.random.default_rng(seed=None)` — Modern RNG. Always seed for reproducibility.                                 | `rng = np.random.default_rng(42)`<br/>`samples = rng.normal(0, 1, size=1000)`                                                                                                                                                                                                                |
| `rng.choice()`            | `rng.choice(a, size=None, replace=True, p=None)` — Sample from array, with/without replacement, optional weights. | `rng.choice([10, 20, 30], size=5, p=[0.6, 0.3, 0.1])`                                                                                                                                                                                                                                        |
| Bootstrap resample        | Sample with replacement to estimate sampling distributions.                                                       | `def bootstrap(data, stat_fn, n=1000, rng=None):`<br/>` rng = rng or np.random.default_rng(0)`<br/>` n_data = len(data)`<br/>` return np.array([stat_fn(rng.choice(data, n_data, replace=True)) for _ in range(n)])`                                                                         |
| Permutation test          | Shuffle labels to build null distribution of a test statistic.                                                    | `def perm_test(a, b, stat=lambda a, b: a.mean() - b.mean(), n=10_000):`<br/>` obs = stat(a, b)`<br/>` all_ = np.concatenate([a, b])`<br/>` null = np.array([stat(*np.split(np.random.permutation(all_), [len(a)])) for _ in range(n)])`<br/>` return obs, np.mean(np.abs(null) >= abs(obs))` |
| Inverse-CDF sampling      | Sample from arbitrary distribution: $X = F^{-1}(U)$ where $U \sim \text{Uniform}(0,1)$.                           | `u = rng.uniform(size=1000)`<br/>`x = norm.ppf(u) # normal samples`                                                                                                                                                                                                                          |
| Rejection sampling        | Accept proposals from envelope distribution with probability proportional to target density.                      | `def reject(target_pdf, proposal_rvs, M, n=1000):`<br/>` out = []`<br/>` while len(out) < n:`<br/>` x = proposal_rvs()`<br/>` if rng.uniform() < target_pdf(x) / (M * proposal_pdf(x)):`<br/>` out.append(x)`<br/>` return np.array(out)`                                                    |
| Monte Carlo expectation   | $\mathbb{E}[f(X)] \approx \frac{1}{n}\sum f(x_i)$ where $x_i$ are samples from $X$.                               | `# E[X^2] for X~N(0,1)`<br/>`samples = rng.normal(0, 1, 100_000)`<br/>`print(np.mean(samples**2)) # ~1`                                                                                                                                                                                      |

## Hypothesis testing

| Test                            | Description                                                                                                                                                              | Code example                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| One-sample t-test               | `stats.ttest_1samp(a, popmean, axis=0, alternative='two-sided')` — Sample mean vs hypothesized value. Assumes normality.                                                 | `from scipy import stats`<br/>`stat, p = stats.ttest_1samp(sample, popmean=0)`<br/>`print(f"t={stat:.3f}, p={p:.4f}")`       |
| Two-sample (independent) t-test | `stats.ttest_ind(a, b, equal_var=True, alternative='two-sided')` — Compare two group means. Use `equal_var=False` (Welch's) for unequal variance.                        | `stat, p = stats.ttest_ind(group_a, group_b, equal_var=False)`                                                               |
| Paired t-test                   | `stats.ttest_rel(a, b, alternative='two-sided')` — Compare paired/matched samples.                                                                                       | `stat, p = stats.ttest_rel(before, after)`                                                                                   |
| One-way ANOVA                   | `stats.f_oneway(*samples)` — Test that 3+ group means are equal.                                                                                                         | `stat, p = stats.f_oneway(grp_a, grp_b, grp_c)`                                                                              |
| Chi-square independence         | `stats.chi2_contingency(observed, correction=True)` — Test association between categorical variables. Returns `(stat, p, dof, expected)`.                                | `stat, p, dof, exp = stats.chi2_contingency([[40, 60], [30, 70]])`                                                           |
| Chi-square goodness-of-fit      | `stats.chisquare(f_obs, f_exp=None, ddof=0)` — Test if observed frequencies match expected.                                                                              | `stat, p = stats.chisquare(f_obs=[16, 18, 16, 14], f_exp=[16, 16, 16, 16])`                                                  |
| Mann-Whitney U                  | `stats.mannwhitneyu(x, y, alternative='two-sided')` — Non-parametric two-sample test. Compares distributions, not just means.                                            | `stat, p = stats.mannwhitneyu(group_a, group_b)`                                                                             |
| Wilcoxon signed-rank            | `stats.wilcoxon(x, y=None, alternative='two-sided')` — Non-parametric paired test.                                                                                       | `stat, p = stats.wilcoxon(before, after)`                                                                                    |
| Kolmogorov-Smirnov              | `stats.ks_2samp(data1, data2, alternative='two-sided')` — Compare two distributions (any shape).                                                                         | `stat, p = stats.ks_2samp(sample_a, sample_b)`                                                                               |
| Shapiro-Wilk normality          | `stats.shapiro(x)` — Test if a sample is normally distributed. Use for small samples (&lt;5000).                                                                           | `stat, p = stats.shapiro(sample)`                                                                                            |
| Levene's variance test          | `stats.levene(*samples, center='median')` — Test equal variances across groups.                                                                                          | `stat, p = stats.levene(grp_a, grp_b, grp_c)`                                                                                |
| Multiple-testing correction     | `from statsmodels.stats.multitest import multipletests`<br/>`multipletests(pvals, alpha=0.05, method='fdr_bh')` — Control FDR (Benjamini-Hochberg) or FWER (Bonferroni). | `from statsmodels.stats.multitest import multipletests`<br/>`reject, p_adj, _, _ = multipletests(p_values, method="fdr_bh")` |

## Confidence intervals and bootstrap

| Method                     | Description                                                                                                                                                                            | Code example                                                                                                                                       |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Normal-approx CI for mean  | `mean ± z * (std / sqrt(n))` where `z = 1.96` for 95%. Valid when n is large (CLT).                                                                                                    | `se = sample.std(ddof=1) / np.sqrt(len(sample))`<br/>`ci = (sample.mean() - 1.96 * se, sample.mean() + 1.96 * se)`                                 |
| t-based CI for mean        | Use `stats.t.ppf(0.975, df=n-1)` instead of 1.96 when n is small or population std unknown.                                                                                            | `from scipy.stats import t`<br/>`crit = t.ppf(0.975, df=len(sample)-1)`<br/>`ci = (sample.mean() - crit * se, sample.mean() + crit * se)`          |
| Proportion CI (Wilson)     | `from statsmodels.stats.proportion import proportion_confint`<br/>`proportion_confint(count, nobs, alpha=0.05, method='wilson')` — Better than normal-approx for small n or extreme p. | `from statsmodels.stats.proportion import proportion_confint`<br/>`lo, hi = proportion_confint(count=45, nobs=100, method="wilson")`               |
| Bootstrap CI (percentile)  | Resample with replacement, take `[2.5%, 97.5%]` of bootstrapped statistics.                                                                                                            | `boots = [np.mean(rng.choice(sample, len(sample), replace=True)) for _ in range(5000)]`<br/>`ci = np.quantile(boots, [0.025, 0.975])`              |
| Bootstrap CI (BCa)         | `scipy.stats.bootstrap(data, statistic, n_resamples=9999, confidence_level=0.95, method='BCa')` — Bias-corrected and accelerated; preferred for skewed distributions.                  | `from scipy.stats import bootstrap`<br/>`res = bootstrap((sample,), np.mean, n_resamples=5000, method="BCa")`<br/>`print(res.confidence_interval)` |
| CI for difference of means | `(diff) ± t * sqrt(s_a²/n_a + s_b²/n_b)`. Welch's formula.                                                                                                                             | `diff = a.mean() - b.mean()`<br/>`se = np.sqrt(a.var(ddof=1)/len(a) + b.var(ddof=1)/len(b))`<br/>`ci = (diff - 1.96*se, diff + 1.96*se)`           |
| CI for correlation         | Fisher z-transform: `z = arctanh(r)`, then build CI in z-space, transform back via `tanh`.                                                                                             | `r = np.corrcoef(x, y)[0, 1]`<br/>`z = np.arctanh(r)`<br/>`se = 1 / np.sqrt(len(x) - 3)`<br/>`ci = np.tanh((z - 1.96*se, z + 1.96*se))`            |

## Bayesian basics

| Method                  | Description                                                                                                    | Code example                                                                                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bayes rule              | $P(\theta \mid D) = \frac{P(D \mid \theta)\,P(\theta)}{P(D)}$ — Posterior $\propto$ likelihood $\times$ prior. | `posterior = (likelihood * prior) / evidence`                                                                                                                                    |
| Beta-Binomial conjugate | Prior `Beta(a, b)` + binomial likelihood → Posterior `Beta(a + k, b + n - k)`.                                 | `a_post = a_prior + successes`<br/>`b_post = b_prior + failures`                                                                                                                 |
| Normal-Normal conjugate | Prior `N(mu0, tau0²)` + known-variance normal likelihood → Posterior is also normal with shrunk mean.          | `precision = 1/tau0**2 + n/sigma**2`<br/>`mu_post = (mu0/tau0**2 + sum_x/sigma**2) / precision`                                                                                  |
| Gamma-Poisson conjugate | Prior `Gamma(a, b)` + Poisson likelihood → Posterior `Gamma(a + sum_x, b + n)`.                                | `a_post = a_prior + sum_counts`<br/>`b_post = b_prior + n_observations`                                                                                                          |
| MAP estimate            | $\hat\theta_{\text{MAP}} = \arg\max_\theta P(D \mid \theta) P(\theta)$. Reduces to MLE under uniform prior.    | `# Beta-Binomial MAP = (a_post - 1) / (a_post + b_post - 2)`                                                                                                                     |
| Posterior predictive    | Average likelihood over posterior. For Beta-Binomial: `Beta-Binomial(n_new, a_post, b_post)`.                  | `from scipy.stats import betabinom`<br/>`pred_pmf = betabinom.pmf(k=range(11), n=10, a=a_post, b=b_post)`                                                                        |
| Credible interval       | Posterior quantile range. Bayesian analogue of confidence interval.                                            | `from scipy.stats import beta`<br/>`ci = beta.ppf([0.025, 0.975], a_post, b_post)`                                                                                               |
| Bayes factor            | $\text{BF}_{10} = \frac{P(D \mid H_1)}{P(D \mid H_0)}$ — Evidence ratio between hypotheses.                    | `# Approximation via BIC: BF ≈ exp((BIC_0 - BIC_1) / 2)`                                                                                                                         |
| PyMC quick model        | `pm.Model()` context + `pm.Normal`, `pm.Beta`, etc. for priors and likelihood; `pm.sample()` for posterior.    | `import pymc as pm`<br/>`with pm.Model() as model:`<br/>` p = pm.Beta("p", alpha=1, beta=1)`<br/>` obs = pm.Bernoulli("obs", p=p, observed=data)`<br/>` trace = pm.sample(1000)` |

## Information theory and ML metrics

| Method                           | Description                                                                                                | Code example                                                                                                                                                                                                                                                                                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Entropy                          | $H(p) = -\sum_i p_i \log p_i$ — Uncertainty of a distribution.                                             | `from scipy.stats import entropy`<br/>`p = np.array([0.2, 0.8])`<br/>`print(entropy(p, base=2)) # bits`                                                                                                                                                                                                                    |
| Cross entropy                    | $H(p, q) = -\sum_i p_i \log q_i$ — Expected log loss when true distribution is `p` and model predicts `q`. | `# logits + integer labels (PyTorch)`<br/>`loss = F.cross_entropy(logits, labels)`                                                                                                                                                                                                                                         |
| KL divergence                    | KL divergence compares `p` against `q` with sum over `p_i * log(p_i / q_i)`. Asymmetric. Zero iff `p == q`. | `from scipy.stats import entropy`<br/>`kl = entropy(p, q, base=2) # uses KL when 2 args`                                                                                                                                                                                                                                   |
| JS divergence                    | Symmetric variant of KL divergence using midpoint distribution `m = (p + q) / 2`.                          | `m = (p + q) / 2`<br/>`js = 0.5 * entropy(p, m) + 0.5 * entropy(q, m)`                                                                                                                                                                                                                                                     |
| Mutual information               | Reduction in uncertainty about Y given X; equivalent to comparing joint vs independent distributions.      | `from sklearn.metrics import mutual_info_score`<br/>`mi = mutual_info_score(labels_x, labels_y)`                                                                                                                                                                                                                           |
| Perplexity                       | $\exp(\text{cross entropy})$ — Standard LM evaluation metric. Lower is better.                             | `perplexity = np.exp(cross_entropy_loss)`                                                                                                                                                                                                                                                                                  |
| Log loss (binary)                | $-[y \log p + (1-y) \log(1-p)]$.                                                                           | `from sklearn.metrics import log_loss`<br/>`log_loss(y_true, y_proba)`                                                                                                                                                                                                                                                     |
| Expected Calibration Error (ECE) | Average gap between predicted confidence and observed accuracy across bins.                                | `def ece(probs, labels, n_bins=10):`<br/>` bins = pd.cut(probs, n_bins, labels=False)`<br/>` df = pd.DataFrame({"p": probs, "y": labels, "b": bins})`<br/>` grp = df.groupby("b").agg(conf=("p", "mean"), acc=("y", "mean"), n=("y", "size"))`<br/>` return (grp["n"] / len(df) * (grp["conf"] - grp["acc"]).abs()).sum()` |
| Brier score                      | Mean squared error between predicted probability and outcome. Proper scoring rule.                         | `from sklearn.metrics import brier_score_loss`<br/>`brier_score_loss(y_true, y_proba)`                                                                                                                                                                                                                                     |

## A/B testing and experimentation

| Method                             | Description                                                                                                                                              | Code example                                                                                                                                                                         |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Sample size for proportions        | `from statsmodels.stats.power import NormalIndPower`<br/>`NormalIndPower().solve_power(effect_size=es, alpha=0.05, power=0.8, alternative='two-sided')`. | `from statsmodels.stats.power import NormalIndPower`<br/>`n = NormalIndPower().solve_power(effect_size=0.1, alpha=0.05, power=0.8)`<br/>`print(int(np.ceil(n)))`                     |
| Cohen's h (proportion effect size) | $h = 2\arcsin(\sqrt{p_1}) - 2\arcsin(\sqrt{p_2})$.                                                                                                       | `def cohens_h(p1, p2):`<br/>` return 2 * (np.arcsin(np.sqrt(p1)) - np.arcsin(np.sqrt(p2)))`                                                                                          |
| Cohen's d (mean effect size)       | $d = (\mu_1 - \mu_2) / s_{\text{pooled}}$.                                                                                                               | `def cohens_d(a, b):`<br/>` sp = np.sqrt(((len(a)-1)*a.var(ddof=1) + (len(b)-1)*b.var(ddof=1)) / (len(a)+len(b)-2))`<br/>` return (a.mean() - b.mean()) / sp`                        |
| Two-proportion z-test              | `from statsmodels.stats.proportion import proportions_ztest`<br/>`proportions_ztest(count, nobs, alternative='two-sided')`.                              | `from statsmodels.stats.proportion import proportions_ztest`<br/>`stat, p = proportions_ztest(count=[120, 100], nobs=[1000, 1000])`                                                  |
| Lift and relative effect           | `lift = rate_b / rate_a - 1`. Often more useful than absolute difference.                                                                                | `lift = (rate_b - rate_a) / rate_a`                                                                                                                                                  |
| CUPED variance reduction           | Use a pre-experiment covariate to reduce metric variance: $Y' = Y - \theta(X - \bar{X})$ where $\theta = \text{Cov}(X,Y)/\text{Var}(X)$.                 | `theta = np.cov(pre, metric, ddof=1)[0, 1] / pre.var(ddof=1)`<br/>`metric_adj = metric - theta * (pre - pre.mean())`                                                                 |
| Sequential testing risk            | Repeated peeking at p-values inflates false positives. Use alpha-spending (e.g., O'Brien-Fleming) or Bayesian decision rules.                            | `# Never re-evaluate p-value daily without correction.`                                                                                                                              |
| SRM check (Sample Ratio Mismatch)  | Validate that assignment matches design. Use chi-square.                                                                                                 | `from scipy.stats import chisquare`<br/>`stat, p = chisquare(f_obs=[na, nb], f_exp=[(na+nb)/2]*2)`                                                                                   |
| Stratified A/B test                | Block by user segment to reduce variance and prevent imbalance.                                                                                          | `df.groupby("segment").apply(lambda g: ttest_ind(g[g.variant=='A'].metric, g[g.variant=='B'].metric))`                                                                               |
| Bayesian A/B (beta-binomial)       | Posteriors `Beta(α+k_a, β+n_a-k_a)` and `Beta(α+k_b, β+n_b-k_b)`. P(B > A) via Monte Carlo.                                                              | `from scipy.stats import beta`<br/>`a_post = beta(1 + ka, 1 + na - ka).rvs(10_000)`<br/>`b_post = beta(1 + kb, 1 + nb - kb).rvs(10_000)`<br/>`p_b_better = (b_post > a_post).mean()` |

## Senior ML statistics and pitfalls

| Method                                      | Description                                                                                               | Code example                                                                                                                                                |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bias-variance decomposition                 | Generalization error = bias² + variance + irreducible noise.                                              | `# Estimate via repeated subsampling + variance across fits`                                                                                                |
| Learning curve                              | Plot train + validation error vs training set size. Diagnose if more data helps.                          | `from sklearn.model_selection import learning_curve`<br/>`sizes, train, val = learning_curve(model, X, y, train_sizes=np.linspace(0.1, 1.0, 5), cv=5)`      |
| Calibration error (ECE/MCE)                 | Maximum/expected gap between predicted confidence and observed accuracy.                                  | `# See ECE definition above`                                                                                                                                |
| Power analysis (always do before launching) | `TTestIndPower().solve_power(effect_size, alpha, power)` — Estimate required N.                           | `from statsmodels.stats.power import TTestIndPower`<br/>`n = TTestIndPower().solve_power(effect_size=0.2, alpha=0.05, power=0.8)`                           |
| Effect size always reported                 | Report Cohen's d, h, or odds ratio — not just p-value. Statistical significance ≠ practical significance. | `# See Cohen's d/h above`                                                                                                                                   |
| Hierarchical shrinkage                      | For small subgroups, blend the local estimate with the global mean.                                       | `theta_hat = (n * x_bar + tau * mu) / (n + tau)`                                                                                                            |
| Delta method (SE of transformed estimate)   | $\text{Var}(g(\hat\theta)) \approx g'(\hat\theta)^2 \text{Var}(\hat\theta)$.                              | `# For ratio x/y: Var ≈ (1/y²)Var(x) + (x²/y⁴)Var(y) - 2(x/y³)Cov(x,y)`                                                                                     |
| Stratified bootstrap                        | Resample within strata (classes, segments) to preserve balance.                                           | `pos_idx = rng.choice(pos, len(pos), replace=True)`<br/>`neg_idx = rng.choice(neg, len(neg), replace=True)`<br/>`boot = np.concatenate([pos_idx, neg_idx])` |
| Bonferroni correction                       | Adjust alpha: `alpha_corrected = alpha / num_tests`. Conservative; controls FWER.                         | `alpha_corr = 0.05 / 20 # 20 simultaneous tests`                                                                                                            |
| FDR control (Benjamini-Hochberg)            | Less conservative than Bonferroni; controls expected false discovery rate.                                | `multipletests(p_values, method="fdr_bh")`                                                                                                                  |
| Selection bias diagnostics                  | Check whether observation probability correlates with target. Critical for online experiments.            | `# Compare distributions of features between observed vs missing`                                                                                           |
| Reproducibility checklist                   | Seed all RNGs, version-pin dependencies, save preprocessing artifacts.                                    | `np.random.seed(42); torch.manual_seed(42); random.seed(42)`                                                                                                |

## Common patterns

| Pattern                                | Code                                                                                                                                                                                                                                  |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 95% confidence interval for a mean     | `from scipy.stats import t`<br/>`se = sample.std(ddof=1) / np.sqrt(len(sample))`<br/>`crit = t.ppf(0.975, df=len(sample)-1)`<br/>`ci = (sample.mean() - crit*se, sample.mean() + crit*se)`                                            |
| A/B test (two-proportion z-test)       | `from statsmodels.stats.proportion import proportions_ztest`<br/>`stat, p = proportions_ztest(count=[k_a, k_b], nobs=[n_a, n_b])`<br/>`lift = (k_b/n_b) / (k_a/n_a) - 1`<br/>`print(f"lift={lift:.2%}, p={p:.4f}")`                   |
| Bootstrap CI for ML metric             | `from sklearn.metrics import roc_auc_score`<br/>`rng = np.random.default_rng(0)`<br/>`scores = [roc_auc_score(y[i], p[i]) for i in (rng.choice(len(y), len(y)) for _ in range(1000))]`<br/>`ci = np.quantile(scores, [0.025, 0.975])` |
| Class imbalance baseline               | `baseline_acc = np.bincount(y).max() / len(y)`<br/>`print(f"Always-predict-majority accuracy = {baseline_acc:.3f}")`                                                                                                                  |
| Z-score normalization                  | `z = (x - x.mean(axis=0)) / x.std(axis=0, ddof=1)`                                                                                                                                                                                    |
| Outlier robust summary                 | `q1, q3 = np.quantile(x, [0.25, 0.75])`<br/>`iqr = q3 - q1`<br/>`outliers = (x < q1 - 1.5*iqr) \| (x > q3 + 1.5*iqr)`                                                                                                                 |
| Stratified group split                 | `from sklearn.model_selection import GroupShuffleSplit`<br/>`gss = GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=0)`<br/>`train_idx, test_idx = next(gss.split(X, y, groups=user_ids))`                                   |
| Time-based split for forecasting       | `train = df[df.date < cutoff]`<br/>`test = df[df.date >= cutoff]`                                                                                                                                                                     |
| Slice metrics by segment               | `df.groupby("segment").apply(lambda g: roc_auc_score(g.y, g.pred))`                                                                                                                                                                   |
| Calibration check                      | `from sklearn.calibration import calibration_curve`<br/>`prob_true, prob_pred = calibration_curve(y, probs, n_bins=10, strategy="quantile")`<br/>`plt.plot(prob_pred, prob_true); plt.plot([0,1],[0,1],'--')`                         |
| Decision threshold optimization        | `thresholds = np.linspace(0, 1, 101)`<br/>`best_thr = max(thresholds, key=lambda t: utility(y, prob >= t))`                                                                                                                           |
| Bayesian beta-binomial conversion rate | `from scipy.stats import beta`<br/>`# Posterior after k successes in n trials, uniform Beta(1,1) prior`<br/>`post = beta(1 + k, 1 + n - k)`<br/>`ci = post.ppf([0.025, 0.975])`                                                       |
| Multiple-testing correction            | `from statsmodels.stats.multitest import multipletests`<br/>`reject, p_adj, _, _ = multipletests(p_values, alpha=0.05, method="fdr_bh")`                                                                                              |
