# Python Master Cheatsheet

## Beginner

| Method                                  | Method description                                                                                                                                                                | Code example                                                                                                                                                                                          |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `print()`                               | `print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)` — Writes values to standard output. Useful for scripts, debugging, and interview trace walkthroughs.           | `name = "Ada"`<br/>`score = 95`<br/>`print(f"{name=} {score=}")`                                                                                                                                      |
| `type()`                                | `type(object)` — Returns the runtime type of an object. Useful for debugging, but avoid overusing it for business logic.                                                          | `value = [1, 2, 3]`<br/>`print(type(value).__name__)`<br/>`# list`                                                                                                                                    |
| `isinstance()`                          | `isinstance(object, classinfo)` — Checks whether an object belongs to one or more types. `classinfo` can be a class or a tuple of classes. Preferred over direct `type()` checks. | `def normalize(value):`<br/>` if isinstance(value, str):`<br/>` return value.strip()`<br/>` if isinstance(value, (int, float)):`<br/>` return str(value)`<br/>` raise TypeError("unsupported value")` |
| `len()`                                 | `len(s)` — Returns the size of a sequence, collection, or mapping.                                                                                                                | `users = ["Ada", "Linus", "Grace"]`<br/>`if len(users) >= 3:`<br/>` print("team is ready")`                                                                                                           |
| `range()`                               | `range(stop)` / `range(start, stop, step=1)` — Produces a lazy integer sequence for counted loops.                                                                                | `total = 0`<br/>`for number in range(1, 6):`<br/>` total += number`<br/>`print(total) # 15`                                                                                                           |
| `enumerate()`                           | `enumerate(iterable, start=0)` — Iterates with both index and value without manually maintaining a counter.                                                                       | `names = ["Ada", "Linus", "Grace"]`<br/>`for rank, name in enumerate(names, start=1):`<br/>` print(rank, name)`                                                                                       |
| `zip()`                                 | `zip(*iterables, strict=False)` — Combines multiple iterables position by position. Stops at the shortest input (or raises with `strict=True`).                                   | `names = ["Ada", "Linus"]`<br/>`scores = [95, 88]`<br/>`report = dict(zip(names, scores))`<br/>`print(report)`                                                                                        |
| `input()`                               | `input(prompt='')` — Reads user input as a string. Convert and validate before using it.                                                                                          | `raw_age = input("Age: ").strip()`<br/>`age = int(raw_age)`<br/>`print(age >= 18)`                                                                                                                    |
| `str.strip()`                           | `str.strip(chars=None)` — Removes whitespace (default) or selected characters from both ends. Variants: `lstrip`, `rstrip`.                                                       | `raw_email = " ADA@EXAMPLE.COM "`<br/>`email = raw_email.strip().lower()`<br/>`print(email)`                                                                                                          |
| `str.split()`                           | `str.split(sep=None, maxsplit=-1)` — Splits text into a list using whitespace or a delimiter.                                                                                     | `row = "alice,admin,active"`<br/>`name, role, status = row.split(",")`<br/>`print(name, role, status)`                                                                                                |
| `str.join()`                            | `str.join(iterable)` — Joins strings with a separator. Prefer over repeated `+=` concatenation in loops.                                                                          | `parts = ["api", "v1", "users"]`<br/>`path = "/" + "/".join(parts)`<br/>`print(path)`                                                                                                                 |
| `str.replace()`                         | `str.replace(old, new, count=-1)` — Replaces matching substrings. Useful for normalization and cleanup.                                                                           | `title = "python master cheatsheet"`<br/>`slug = title.replace(" ", "-")`<br/>`print(slug)`                                                                                                           |
| `str.startswith()` and `str.endswith()` | `str.startswith(prefix, start=0, end=len(s))` / `str.endswith(suffix, start=0, end=len(s))` — Test prefixes/suffixes for routing, validation, file handling.                      | `filename = "report.csv"`<br/>`if filename.endswith(".csv"):`<br/>` print("parse as CSV")`                                                                                                            |
| `list.append()`                         | `list.append(item)` — Adds one item to the end of a list.                                                                                                                         | `tasks = []`<br/>`tasks.append("read input")`<br/>`tasks.append("validate input")`<br/>`print(tasks)`                                                                                                 |
| `list.extend()`                         | `list.extend(iterable)` — Adds all values from another iterable to a list.                                                                                                        | `errors = ["missing email"]`<br/>`errors.extend(["bad age", "bad role"])`<br/>`print(errors)`                                                                                                         |
| `list.pop()`                            | `list.pop(index=-1)` — Removes and returns an item. Default is the last item. Useful for stacks.                                                                                  | `stack = ["parse", "validate", "save"]`<br/>`while stack:`<br/>` step = stack.pop()`<br/>` print(step)`                                                                                               |
| `list.sort()`                           | `list.sort(*, key=None, reverse=False)` — Sorts in place. Use when mutating the original list is intended.                                                                        | `users = [{"name": "Ada", "age": 36}, {"name": "Linus", "age": 29}]`<br/>`users.sort(key=lambda user: user["age"])`<br/>`print(users)`                                                                |
| `sorted()`                              | `sorted(iterable, *, key=None, reverse=False)` — Returns a new sorted list without changing the original iterable.                                                                | `scores = [91, 75, 99, 88]`<br/>`top_three = sorted(scores, reverse=True)[:3]`<br/>`print(top_three)`                                                                                                 |
| `dict.get()`                            | `dict.get(key, default=None)` — Reads a key with a fallback instead of raising `KeyError`.                                                                                        | `payload = {"name": "Ada"}`<br/>`role = payload.get("role", "guest")`<br/>`print(role)`                                                                                                               |
| `dict.items()`                          | `dict.items()` — Returns a view of `(key, value)` pairs. Iterates lazily.                                                                                                         | `config = {"debug": False, "retries": 3}`<br/>`for key, value in config.items():`<br/>` print(f"{key}: {value}")`                                                                                     |
| `set.add()`                             | `set.add(elem)` — Adds a unique item to a set. Does nothing if already present.                                                                                                   | `seen = set()`<br/>`for user_id in [1, 2, 1, 3]:`<br/>` seen.add(user_id)`<br/>`print(seen)`                                                                                                          |
| `set.discard()`                         | `set.discard(elem)` — Removes an item if it exists, no error if it doesn't. (Use `.remove()` to raise on missing.)                                                                | `active_users = {1, 2, 3}`<br/>`active_users.discard(2)`<br/>`active_users.discard(99)`<br/>`print(active_users)`                                                                                     |
| `in`                                    | Operator: `x in container`. Membership test for strings, lists, sets, tuples, dictionary keys.                                                                                    | `permissions = {"read", "write"}`<br/>`if "write" in permissions:`<br/>` print("allowed")`                                                                                                            |

## Intermediate

| Method                            | Method description                                                                                                                                                                                       | Code example                                                                                                                                                                           |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| List comprehension                | Syntax: `[expr for item in iterable if condition]`. Builds transformed lists compactly while keeping logic readable.                                                                                     | `nums = [1, 2, 3, 4, 5]`<br/>`squares_of_even = [n * n for n in nums if n % 2 == 0]`<br/>`print(squares_of_even)`                                                                      |
| Dict comprehension                | Syntax: `{key_expr: value_expr for item in iterable if condition}`. Common for indexing records by ID.                                                                                                   | `users = [{"id": 1, "name": "Ada"}, {"id": 2, "name": "Linus"}]`<br/>`users_by_id = {user["id"]: user for user in users}`<br/>`print(users_by_id[1]["name"])`                          |
| Set comprehension                 | Syntax: `{expr for item in iterable if condition}`. Builds a unique collection while transforming values.                                                                                                | `emails = ["A@EXAMPLE.COM", "b@example.com", "a@example.com"]`<br/>`domains = {email.lower().split("@")[1] for email in emails}`<br/>`print(domains)`                                  |
| Generator expression              | Syntax: `(expr for item in iterable if condition)`. Lazily produces values without allocating a full list.                                                                                               | `orders = [{"total": 20}, {"total": 35}, {"total": 15}]`<br/>`revenue = sum(order["total"] for order in orders)`<br/>`print(revenue)`                                                  |
| `any()`                           | `any(iterable)` — Returns `True` when at least one item is truthy. Short-circuits on first truthy.                                                                                                       | `users = [{"role": "user"}, {"role": "admin"}]`<br/>`has_admin = any(user["role"] == "admin" for user in users)`<br/>`print(has_admin)`                                                |
| `all()`                           | `all(iterable)` — Returns `True` when every item is truthy (or the iterable is empty). Short-circuits on first falsy.                                                                                    | `required = ["email", "password"]`<br/>`payload = {"email": "a@example.com", "password": "secret"}`<br/>`is_valid = all(field in payload for field in required)`<br/>`print(is_valid)` |
| `map()`                           | `map(function, *iterables)` — Applies a function lazily to every item. Best when the function is already named.                                                                                          | `raw_names = ["ada lovelace", "grace hopper"]`<br/>`names = list(map(str.title, raw_names))`<br/>`print(names)`                                                                        |
| `filter()`                        | `filter(function, iterable)` — Keeps items that pass a predicate. Comprehensions are often clearer for simple filters.                                                                                   | `users = [{"name": "Ada", "active": True}, {"name": "Linus", "active": False}]`<br/>`active = list(filter(lambda user: user["active"], users))`<br/>`print(active)`                    |
| `lambda`                          | Syntax: `lambda arg1, arg2: expression`. Anonymous function, often for sort keys and callbacks.                                                                                                          | `users = [{"name": "Ada", "age": 36}, {"name": "Linus", "age": 29}]`<br/>`youngest_first = sorted(users, key=lambda user: user["age"])`<br/>`print(youngest_first)`                    |
| `min()` and `max()`               | `min(iterable, *, key=None, default=...)` / `max(iterable, *, key=None, default=...)` — Smallest/largest item, optionally by a custom key.                                                               | `events = [{"id": 1, "ts": 10}, {"id": 2, "ts": 30}]`<br/>`latest = max(events, key=lambda event: event["ts"])`<br/>`print(latest)`                                                    |
| Slicing                           | Syntax: `seq[start:stop:step]`. Negative indices count from the end; step `-1` reverses.                                                                                                                 | `items = ["a", "b", "c", "d", "e"]`<br/>`last_three = items[-3:]`<br/>`every_other = items[::2]`<br/>`print(last_three, every_other)`                                                  |
| Unpacking                         | Syntax: `a, b, *rest = iterable` or `a, *middle, b = iterable`. Star captures variable-length sections.                                                                                                  | `record = ["Ada", "admin", "active", "2026-01-01"]`<br/>`name, role, *metadata = record`<br/>`print(name, role, metadata)`                                                             |
| `pathlib.Path`                    | `Path(*pathsegments)` — Filesystem paths as objects. Chain with `/`; key methods: `.read_text(encoding=None)`, `.write_text(data, encoding=None)`, `.exists()`, `.mkdir(parents=False, exist_ok=False)`. | `from pathlib import Path`<br/>`root = Path("data")`<br/>`path = root / "users.txt"`<br/>`path.write_text("Ada\\n", encoding="utf-8")`                                                 |
| `open()`                          | `open(file, mode='r', buffering=-1, encoding=None, errors=None, newline=None)` — Open a file. Use a context manager so it closes on failure.                                                             | `with open("users.txt", "w", encoding="utf-8") as file:`<br/>` file.write("Ada\\n")`<br/>`with open("users.txt", encoding="utf-8") as file:`<br/>` print(file.read())`                 |
| `json.loads()` and `json.dumps()` | `json.loads(s, **kwargs)` / `json.dumps(obj, indent=None, ensure_ascii=True, sort_keys=False, default=None)` — Convert between JSON strings and Python objects.                                          | `import json`<br/>`raw = '{"name": "Ada", "active": true}'`<br/>`payload = json.loads(raw)`<br/>`print(json.dumps(payload, indent=2))`                                                 |
| `try` and `except`                | Syntax: `try: ... except ExceptionType as e: ... else: ... finally: ...`. Handles expected failures while keeping the risky section small.                                                               | `def parse_age(raw):`<br/>` try:`<br/>` return int(raw)`<br/>` except ValueError:`<br/>` return None`                                                                                  |
| `raise`                           | Syntax: `raise Exception(msg)` or `raise NewException from cause`. Signals that a function cannot continue correctly.                                                                                    | `def withdraw(balance, amount):`<br/>` if amount > balance:`<br/>` raise ValueError("insufficient funds")`<br/>` return balance - amount`                                              |
| `with`                            | Syntax: `with context_manager as name: ...` (or chained `with a as x, b as y:`). Sets up and cleans up resources deterministically.                                                                      | `from threading import Lock`<br/>`lock = Lock()`<br/>`with lock:`<br/>` print("safe critical section")`                                                                                |
| Keyword-only arguments            | Syntax: `def f(positional, *, keyword_only=default)`. Anything after `*` must be passed by name.                                                                                                         | `def retry(operation, *, attempts=3, delay=1):`<br/>` for _ in range(attempts):`<br/>` result = operation()`<br/>` if result:`<br/>` return result`                                    |
| `*args` and `**kwargs`            | Syntax: `def f(*args, **kwargs)`. `*args` collects positional, `**kwargs` collects keyword. Use for wrappers and decorators.                                                                             | `def audit(event, *tags, **fields):`<br/>` print(event, tags, fields)`<br/>`audit("login", "security", user_id=42, success=True)`                                                      |
| `dataclasses.dataclass`           | `@dataclass(init=True, repr=True, eq=True, order=False, frozen=False, slots=False, kw_only=False)` — Generates `__init__`, `__repr__`, `__eq__`.                                                         | `from dataclasses import dataclass`<br/>`@dataclass`<br/>`class User:`<br/>` id: int`<br/>` email: str`<br/>`user = User(1, "ada@example.com")`                                        |
| `typing.Optional`                 | `Optional[X]` is equivalent to `Union[X, None]` (and to `X                                                                                                                                               | None` in 3.10+). Documents that a value may be missing.                                                                                                                                | `from typing import Optional`<br/>`def find_user(user_id: int) -> Optional[str]:`<br/>` return "Ada" if user_id == 1 else None` |
| `typing.Callable`                 | `Callable[[ArgType1, ArgType2], ReturnType]` — Types a callback function. Use `Callable[..., ReturnType]` if args are unknown.                                                                           | `from typing import Callable`<br/>`def apply_twice(fn: Callable[[int], int], value: int) -> int:`<br/>` return fn(fn(value))`<br/>`print(apply_twice(lambda x: x + 1, 3))`             |
| `collections.Counter`             | `Counter(iterable_or_mapping=None)` — Hashable item counts. Methods: `.most_common(n=None)`, `.update(iterable)`, `.subtract(iterable)`.                                                                 | `from collections import Counter`<br/>`words = "to be or not to be".split()`<br/>`counts = Counter(words)`<br/>`print(counts.most_common(2))`                                          |
| `collections.defaultdict`         | `defaultdict(default_factory=None, **kwargs)` — Creates missing values automatically using `default_factory()`. Often used for grouping.                                                                 | `from collections import defaultdict`<br/>`groups = defaultdict(list)`<br/>`for name, team in [("Ada", "A"), ("Linus", "A")]:`<br/>` groups[team].append(name)`                        |
| `collections.deque`               | `deque(iterable=[], maxlen=None)` — Fast queue/stack from both ends. Methods: `.append`, `.appendleft`, `.pop`, `.popleft`, `.rotate(n=1)`.                                                              | `from collections import deque`<br/>`queue = deque(["root"])`<br/>`queue.append("child")`<br/>`print(queue.popleft())`                                                                 |

## Advanced

| Method                         | Method description                                                                                                                                                                      | Code example                                                                                                                                                                                                                                                            |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Decorator                      | Syntax: `@decorator` above `def fn:`. Wraps a function to add behavior such as logging, timing, auth, or caching. Use `@functools.wraps(fn)` on the inner wrapper to preserve metadata. | `from functools import wraps`<br/>`def require_admin(fn):`<br/>` @wraps(fn)`<br/>` def wrapper(user, *args, **kwargs):`<br/>` if user["role"] != "admin":`<br/>` raise PermissionError("admin required")`<br/>` return fn(user, *args, **kwargs)`<br/>` return wrapper` |
| `functools.lru_cache()`        | `@lru_cache(maxsize=128, typed=False)` — Memoizes pure function results. Set `maxsize=None` for unbounded.                                                                              | `from functools import lru_cache`<br/>`@lru_cache(maxsize=1024)`<br/>`def fib(n):`<br/>` return n if n < 2 else fib(n - 1) + fib(n - 2)`<br/>`print(fib(40))`                                                                                                           |
| `functools.cached_property`    | `@cached_property` — Computes an instance property once and caches the result on the instance.                                                                                          | `from functools import cached_property`<br/>`class Report:`<br/>` def __init__(self, rows):`<br/>` self.rows = rows`<br/>` @cached_property`<br/>` def total(self):`<br/>` return sum(row["amount"] for row in self.rows)`                                              |
| `functools.partial()`          | `partial(func, /, *args, **keywords)` — Pre-fills arguments to create a specialized callable.                                                                                           | `from functools import partial`<br/>`def send(to, subject, body):`<br/>` print(to, subject, body)`<br/>`send_welcome = partial(send, subject="Welcome")`<br/>`send_welcome("ada@example.com", body="Hello")`                                                            |
| `itertools.chain()`            | `chain(*iterables)` / `chain.from_iterable(iterable_of_iterables)` — Lazily concatenates multiple iterables.                                                                            | `from itertools import chain`<br/>`db_rows = [{"id": 1}]`<br/>`api_rows = [{"id": 2}]`<br/>`for row in chain(db_rows, api_rows):`<br/>` print(row["id"])`                                                                                                               |
| `itertools.groupby()`          | `groupby(iterable, key=None)` — Groups _adjacent_ items by key. Sort first if you need global grouping.                                                                                 | `from itertools import groupby`<br/>`from operator import itemgetter`<br/>`rows = sorted(rows, key=itemgetter("team"))`<br/>`for team, members in groupby(rows, key=itemgetter("team")):`<br/>` print(team, list(members))`                                             |
| `itertools.product()`          | `product(*iterables, repeat=1)` — Cartesian product. Useful for parameter combinations.                                                                                                 | `from itertools import product`<br/>`for lr, batch_size in product([0.1, 0.01], [32, 64]):`<br/>` print({"lr": lr, "batch_size": batch_size})`                                                                                                                          |
| `operator.itemgetter()`        | `itemgetter(*items)` — Returns a callable that fetches items by key/index. Fast key function for dicts and tuples.                                                                      | `from operator import itemgetter`<br/>`rows = [{"name": "Ada", "score": 95}, {"name": "Linus", "score": 88}]`<br/>`print(sorted(rows, key=itemgetter("score"), reverse=True))`                                                                                          |
| `@property`                    | Decorator (no args). Exposes a method as a read-only attribute. Pair with `@<name>.setter` for writable.                                                                                | `class User:`<br/>` def __init__(self, first, last):`<br/>` self.first = first`<br/>` self.last = last`<br/>` @property`<br/>` def full_name(self):`<br/>` return f"{self.first} {self.last}"`                                                                          |
| `@classmethod`                 | Decorator (no args). First arg becomes `cls` (the class). Useful for named/alternate constructors.                                                                                      | `class User:`<br/>` def __init__(self, id, email):`<br/>` self.id = id`<br/>` self.email = email`<br/>` @classmethod`<br/>` def from_payload(cls, payload):`<br/>` return cls(payload["id"], payload["email"].lower())`                                                 |
| `@staticmethod`                | Decorator (no args). Method has no implicit `self`/`cls`. Namespaces helpers on a class.                                                                                                | `class Email:`<br/>` @staticmethod`<br/>` def normalize(value):`<br/>` return value.strip().lower()`<br/>`print(Email.normalize(" ADA@EXAMPLE.COM "))`                                                                                                                  |
| `__repr__()`                   | `def __repr__(self) -> str` — Returns an unambiguous developer-facing representation. Should ideally be `eval`-able.                                                                    | `class User:`<br/>` def __init__(self, id):`<br/>` self.id = id`<br/>` def __repr__(self):`<br/>` return f"User(id={self.id!r})"`                                                                                                                                       |
| `__eq__()` and `__hash__()`    | `def __eq__(self, other) -> bool` / `def __hash__(self) -> int`. Define equality and hashing together. Keep hash based on immutable identity.                                           | `class UserId:`<br/>` def __init__(self, value):`<br/>` self.value = value`<br/>` def __eq__(self, other):`<br/>` return isinstance(other, UserId) and self.value == other.value`<br/>` def __hash__(self):`<br/>` return hash(self.value)`                             |
| `__iter__()`                   | `def __iter__(self) -> Iterator` — Makes a custom object iterable. Either return an iterator or use `yield`.                                                                            | `class Batch:`<br/>` def __init__(self, items):`<br/>` self.items = items`<br/>` def __iter__(self):`<br/>` return iter(self.items)`<br/>`for item in Batch([1, 2, 3]): print(item)`                                                                                    |
| `__enter__()` and `__exit__()` | `def __enter__(self)` / `def __exit__(self, exc_type, exc_value, traceback) -> bool` — Implements a context manager.                                                                    | `class ManagedConnection:`<br/>` def __enter__(self):`<br/>` self.conn = connect()`<br/>` return self.conn`<br/>` def __exit__(self, exc_type, exc, tb):`<br/>` self.conn.close()`                                                                                      |
| `contextlib.contextmanager`    | `@contextmanager` decorator on a generator function. Code before `yield` is setup; after is teardown.                                                                                   | `from contextlib import contextmanager`<br/>`@contextmanager`<br/>`def timer():`<br/>` start = time.perf_counter()`<br/>` yield`<br/>` print(time.perf_counter() - start)`                                                                                              |
| `yield`                        | Syntax: `yield value` inside a function. Produces values lazily from a generator; pauses and resumes execution.                                                                         | `def chunks(items, size):`<br/>` for index in range(0, len(items), size):`<br/>` yield items[index:index + size]`<br/>`for batch in chunks([1, 2, 3, 4], 2): print(batch)`                                                                                              |
| `yield from`                   | Syntax: `yield from iterable`. Delegates yielding to another iterable or generator.                                                                                                     | `def flatten(groups):`<br/>` for group in groups:`<br/>` yield from group`<br/>`print(list(flatten([[1, 2], [3]])))`                                                                                                                                                    |
| Structural pattern matching    | Syntax: `match expr: case pattern: ... case _: ...`. Matches data shapes; supports mapping, sequence, and class patterns.                                                               | `def handle(command):`<br/>` match command:`<br/>` case {"type": "create", "name": name}:`<br/>` return f"creating {name}"`<br/>` case {"type": "delete", "id": id}:`<br/>` return f"deleting {id}"`<br/>` case _:`<br/>` raise ValueError("unknown command")`          |
| `Protocol`                     | Base class: `class Name(Protocol): method(self, args) -> ReturnType: ...`. Structural typing without inheritance.                                                                       | `from typing import Protocol`<br/>`class UserRepository(Protocol):`<br/>` def get(self, user_id: int) -> dict: ...`<br/>`def load_name(repo: UserRepository, user_id: int):`<br/>` return repo.get(user_id)["name"]`                                                    |
| `TypedDict`                    | `class Name(TypedDict, total=True): field: Type` — Types dictionary-shaped data. `total=False` makes fields optional.                                                                   | `from typing import TypedDict`<br/>`class UserPayload(TypedDict):`<br/>` id: int`<br/>` email: str`<br/>`def normalize(payload: UserPayload) -> UserPayload:`<br/>` return {"id": payload["id"], "email": payload["email"].lower()}`                                    |
| `Enum`                         | `class Name(Enum): MEMBER = value` — Named constants. Variants: `IntEnum`, `StrEnum`, `Flag`.                                                                                           | `from enum import Enum`<br/>`class Status(Enum):`<br/>` PENDING = "pending"`<br/>` DONE = "done"`<br/>`if status is Status.DONE:`<br/>` print("complete")`                                                                                                              |
| `dataclass(slots=True)`        | Argument to `@dataclass`. Uses `__slots__` — reduces memory and prevents dynamic attributes.                                                                                            | `from dataclasses import dataclass`<br/>`@dataclass(slots=True)`<br/>`class Point:`<br/>` x: int`<br/>` y: int`                                                                                                                                                         |
| `dataclass(frozen=True)`       | Argument to `@dataclass`.
