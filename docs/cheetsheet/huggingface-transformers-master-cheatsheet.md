# Hugging Face Transformers Master Cheatsheet

The `transformers` library is the universal interface to pretrained models —
BERT, GPT-2, LLaMA, T5, ViT, Whisper, and thousands more. Master `AutoModel`,
`AutoTokenizer`, pipelines, and the `Trainer` API and you can swap models in one
line.

## Installation and setup

| Method                 | Description                                                                                             | Code example                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| Install                | `pip install transformers` (core). Add `torch`, `datasets`, `accelerate`, `evaluate`, `peft` as needed. | `pip install transformers torch accelerate datasets evaluate`   |
| Login (private models) | `huggingface_hub.login(token=None, add_to_git_credential=False)` — Required for gated repos like Llama. | `from huggingface_hub import login`<br/>`login(token="hf_xxx")` |
| Set cache directory    | Env var: `HF_HOME=/path/to/cache` (or `TRANSFORMERS_CACHE`). Defaults to `~/.cache/huggingface`.        | `export HF_HOME=/data/hf-cache`                                 |
| Set device map         | Arg: `device_map="auto"` in `from_pretrained()` — Auto-shard across GPUs/CPU.                           | `model = AutoModel.from_pretrained(name, device_map="auto")`    |

## Pipelines (one-line inference)

| Method                          | Description                                                                                                                           | Code example                                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `pipeline()`                    | `pipeline(task, model=None, tokenizer=None, device=None, torch_dtype=None, trust_remote_code=False)` — One-call API for common tasks. | `from transformers import pipeline`<br/>`clf = pipeline("sentiment-analysis")`<br/>`print(clf("I love this!"))`                     |
| Sentiment / text classification | `pipeline("sentiment-analysis", model=name)` — Returns `[{'label': ..., 'score': ...}]`.                                              | `pipeline("sentiment-analysis", model="distilbert-base-uncased-finetuned-sst-2-english")`                                           |
| Zero-shot classification        | `pipeline("zero-shot-classification")` — Classify into arbitrary labels at inference time.                                            | `zsc = pipeline("zero-shot-classification")`<br/>`zsc("I love this restaurant", candidate_labels=["food", "service", "ambience"])`  |
| Question answering              | `pipeline("question-answering")` — Pass `question=` and `context=`.                                                                   | `qa = pipeline("question-answering")`<br/>`qa(question="Who wrote Hamlet?", context="Hamlet was written by Shakespeare.")`          |
| Summarization                   | `pipeline("summarization", model=name)` — Args `max_length=`, `min_length=`, `do_sample=False`.                                       | `summ = pipeline("summarization", model="facebook/bart-large-cnn")`<br/>`summ(long_text, max_length=60, min_length=20)`             |
| Translation                     | `pipeline("translation_en_to_fr", model=name)` or use a multilingual model.                                                           | `pipeline("translation", model="Helsinki-NLP/opus-mt-en-fr")("Hello world")`                                                        |
| Text generation                 | `pipeline("text-generation")` — Args `max_new_tokens=`, `temperature=`, `top_p=`, `do_sample=`.                                       | `gen = pipeline("text-generation", model="gpt2")`<br/>`gen("Once upon a time", max_new_tokens=50, do_sample=True, temperature=0.7)` |
| Conversational / chat           | `pipeline("text-generation", model=chat_model)` — Pass `messages=[{"role": ..., "content": ...}]`.                                    | `chat = pipeline("text-generation", model="meta-llama/Llama-3.1-8B-Instruct")`<br/>`chat([{"role": "user", "content": "Hi"}])`      |
| Named entity recognition        | `pipeline("ner", aggregation_strategy='simple')` — Aggregation merges sub-token entities.                                             | `ner = pipeline("ner", aggregation_strategy="simple")`<br/>`ner("Barack Obama was born in Honolulu.")`                              |
| Fill mask                       | `pipeline("fill-mask")` — Predict the `[MASK]` token.                                                                                 | `fill = pipeline("fill-mask", model="bert-base-uncased")`<br/>`fill("Paris is the [MASK] of France.")`                              |
| Embeddings (feature extraction) | `pipeline("feature-extraction", model=name)` — Returns hidden states.                                                                 | `fe = pipeline("feature-extraction", model="sentence-transformers/all-MiniLM-L6-v2")`                                               |

## AutoModel and AutoTokenizer

| Method                            | Description                                                                                                                                                                        | Code example                                                                                                                                                                                                                    |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AutoTokenizer.from_pretrained()` | `AutoTokenizer.from_pretrained(model_id, use_fast=True, trust_remote_code=False, cache_dir=None)` — Loads matching tokenizer.                                                      | `from transformers import AutoTokenizer`<br/>`tok = AutoTokenizer.from_pretrained("bert-base-uncased")`                                                                                                                         |
| `AutoModel.from_pretrained()`     | `AutoModel.from_pretrained(model_id, torch_dtype=None, device_map=None, low_cpu_mem_usage=False, trust_remote_code=False)` — Loads base model (no task head).                      | `from transformers import AutoModel`<br/>`model = AutoModel.from_pretrained("bert-base-uncased")`                                                                                                                               |
| Task-specific Auto classes        | `AutoModelForSequenceClassification`, `AutoModelForTokenClassification`, `AutoModelForQuestionAnswering`, `AutoModelForCausalLM`, `AutoModelForSeq2SeqLM`, `AutoModelForMaskedLM`. | `from transformers import AutoModelForCausalLM`<br/>`model = AutoModelForCausalLM.from_pretrained("gpt2")`                                                                                                                      |
| `AutoConfig.from_pretrained()`    | `AutoConfig.from_pretrained(model_id, **overrides)` — Just the config (no weights).                                                                                                | `from transformers import AutoConfig`<br/>`cfg = AutoConfig.from_pretrained("bert-base-uncased", num_labels=3)`                                                                                                                 |
| Load with quantization (4-bit)    | `BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type='nf4', bnb_4bit_compute_dtype=torch.bfloat16, bnb_4bit_use_double_quant=True)`.                                         | `from transformers import BitsAndBytesConfig`<br/>`bnb = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4")`<br/>`model = AutoModelForCausalLM.from_pretrained(name, quantization_config=bnb, device_map="auto")` |
| Load with dtype                   | `torch_dtype=torch.bfloat16` (or `torch.float16`) — Half precision for inference.                                                                                                  | `model = AutoModelForCausalLM.from_pretrained(name, torch_dtype=torch.bfloat16, device_map="auto")`                                                                                                                             |
| Save model and tokenizer          | `model.save_pretrained(save_directory)` / `tokenizer.save_pretrained(save_directory)`.                                                                                             | `model.save_pretrained("./my-model")`<br/>`tokenizer.save_pretrained("./my-model")`                                                                                                                                             |
| Push to Hub                       | `model.push_to_hub(repo_id, private=False, token=None)`. Same for tokenizer.                                                                                                       | `model.push_to_hub("username/my-model")`                                                                                                                                                                                        |

## Tokenization

| Method                         | Description                                                                                                                                                                             | Code example                                                                                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Direct call (recommended)      | `tokenizer(text_or_list, padding=False, truncation=False, max_length=None, return_tensors=None, return_attention_mask=True, return_token_type_ids=None)`.                               | `enc = tokenizer("Hello world", padding=True, truncation=True, max_length=128, return_tensors="pt")`                                                        |
| Batch tokenization             | Pass a list of strings — get batched tensors back.                                                                                                                                      | `texts = ["sentence one", "and a longer sentence two"]`<br/>`enc = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")`                    |
| Tokenize sentence pairs        | Two positional args — for NLI, QA, sentence-pair classification.                                                                                                                        | `enc = tokenizer("question?", "context text here.", return_tensors="pt")`                                                                                   |
| Chat templates                 | `tokenizer.apply_chat_template(conversation, tokenize=True, add_generation_prompt=False, return_tensors='pt')`.                                                                         | `messages = [{"role": "user", "content": "Hi"}]`<br/>`input_ids = tokenizer.apply_chat_template(messages, add_generation_prompt=True, return_tensors="pt")` |
| `.encode()` / `.decode()`      | `tokenizer.encode(text, add_special_tokens=True)` → list of IDs. `tokenizer.decode(ids, skip_special_tokens=False)` → string.                                                           | `ids = tokenizer.encode("Hello world")`<br/>`print(tokenizer.decode(ids, skip_special_tokens=True))`                                                        |
| `.batch_decode()`              | `tokenizer.batch_decode(sequences, skip_special_tokens=False, clean_up_tokenization_spaces=True)`.                                                                                      | `texts = tokenizer.batch_decode(generated_ids, skip_special_tokens=True)`                                                                                   |
| Special token IDs              | Attributes: `tokenizer.pad_token_id`, `.eos_token_id`, `.bos_token_id`, `.cls_token_id`, `.sep_token_id`, `.mask_token_id`.                                                             | `print(tokenizer.eos_token_id, tokenizer.pad_token_id)`                                                                                                     |
| Set pad token (GPT-2 has none) | Assign `tokenizer.pad_token = tokenizer.eos_token` before padding batches.                                                                                                              | `tokenizer.pad_token = tokenizer.eos_token`                                                                                                                 |
| Vocabulary size                | Attribute `tokenizer.vocab_size`. Use `len(tokenizer)` if you've added special tokens.                                                                                                  | `print(tokenizer.vocab_size, len(tokenizer))`                                                                                                               |
| Add tokens                     | `tokenizer.add_tokens(new_tokens)` / `tokenizer.add_special_tokens({"additional_special_tokens": ["[SEP_EXTRA]"]})` — Remember to call `model.resize_token_embeddings(len(tokenizer))`. | `tokenizer.add_tokens(["[NEW1]", "[NEW2]"])`<br/>`model.resize_token_embeddings(len(tokenizer))`                                                            |

## Manual forward pass and generation

| Method                | Description                                                                                                                                                                                              | Code example                                                                                                                                                             |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Forward pass          | Call the model with kwargs from tokenizer output. Returns a dataclass-like object with `.logits`, `.last_hidden_state`, etc.                                                                             | `inputs = tokenizer("Hello", return_tensors="pt").to(device)`<br/>`with torch.no_grad():`<br/>` outputs = model(**inputs)`<br/>`print(outputs.logits.shape)`             |
| Get hidden states     | `model(..., output_hidden_states=True)` returns `.hidden_states` (tuple per layer).                                                                                                                      | `outputs = model(**inputs, output_hidden_states=True)`<br/>`print(len(outputs.hidden_states))`                                                                           |
| Get attention weights | `model(..., output_attentions=True)` returns `.attentions`.                                                                                                                                              | `outputs = model(**inputs, output_attentions=True)`                                                                                                                      |
| `.generate()`         | `model.generate(inputs, max_new_tokens=None, do_sample=False, num_beams=1, temperature=1.0, top_p=1.0, top_k=50, repetition_penalty=1.0, no_repeat_ngram_size=0, pad_token_id=None, eos_token_id=None)`. | `out = model.generate(**inputs, max_new_tokens=100, do_sample=True, temperature=0.7, top_p=0.9)`<br/>`print(tokenizer.decode(out[0], skip_special_tokens=True))`         |
| Beam search           | `model.generate(..., num_beams=4, early_stopping=True, no_repeat_ngram_size=3)`.                                                                                                                         | `out = model.generate(**inputs, num_beams=4, max_new_tokens=128)`                                                                                                        |
| Greedy decoding       | `do_sample=False, num_beams=1` (the defaults) — Deterministic.                                                                                                                                           | `out = model.generate(**inputs, max_new_tokens=50)`                                                                                                                      |
| Sampling with top-p   | `do_sample=True, temperature=0.7, top_p=0.9, top_k=50` — Standard creative generation config.                                                                                                            | `out = model.generate(**inputs, do_sample=True, top_p=0.9)`                                                                                                              |
| Stop on token         | `eos_token_id=` (int or list) — Stop generation at specific tokens.                                                                                                                                      | `out = model.generate(**inputs, eos_token_id=tokenizer.eos_token_id)`                                                                                                    |
| Streaming generation  | `TextStreamer(tokenizer, skip_prompt=True, skip_special_tokens=True)` — Print tokens as generated.                                                                                                       | `from transformers import TextStreamer`<br/>`streamer = TextStreamer(tokenizer, skip_prompt=True)`<br/>`model.generate(**inputs, streamer=streamer, max_new_tokens=200)` |
| Batched generation    | Pass batched `input_ids` and `attention_mask`. Tokenize with `padding=True`.                                                                                                                             | `batch = tokenizer(prompts, padding=True, return_tensors="pt").to(device)`<br/>`out = model.generate(**batch, max_new_tokens=50)`                                        |

## Trainer API

| Method                            | Description                                                                                                                                                                                                                                                                                                                                                                     | Code example                                                                                                                                                                                                                                                                                                                                                            |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TrainingArguments`               | `TrainingArguments(output_dir, num_train_epochs=3, per_device_train_batch_size=8, per_device_eval_batch_size=8, learning_rate=5e-5, weight_decay=0.0, warmup_steps=0, warmup_ratio=0.0, logging_steps=500, eval_strategy='no', save_strategy='steps', save_steps=500, gradient_accumulation_steps=1, fp16=False, bf16=False, gradient_checkpointing=False, push_to_hub=False)`. | `from transformers import TrainingArguments`<br/>`args = TrainingArguments(`<br/>` output_dir="./out",`<br/>` num_train_epochs=3,`<br/>` per_device_train_batch_size=16,`<br/>` learning_rate=2e-5,`<br/>` weight_decay=0.01,`<br/>` warmup_ratio=0.06,`<br/>` eval_strategy="epoch",`<br/>` save_strategy="epoch",`<br/>` bf16=True,`<br/>` logging_steps=50,`<br/>`)` |
| `Trainer`                         | `Trainer(model, args, train_dataset=None, eval_dataset=None, tokenizer=None, data_collator=None, compute_metrics=None, callbacks=None)`.                                                                                                                                                                                                                                        | `from transformers import Trainer`<br/>`trainer = Trainer(`<br/>` model=model,`<br/>` args=args,`<br/>` train_dataset=train_ds,`<br/>` eval_dataset=val_ds,`<br/>` tokenizer=tokenizer,`<br/>` data_collator=collator,`<br/>` compute_metrics=compute_metrics,`<br/>`)`<br/>`trainer.train()`                                                                           |
| `compute_metrics`                 | Function `compute_metrics(eval_pred) -> dict` where `eval_pred = (predictions, labels)`.                                                                                                                                                                                                                                                                                        | `import evaluate`<br/>`metric = evaluate.load("accuracy")`<br/>`def compute_metrics(eval_pred):`<br/>` logits, labels = eval_pred`<br/>` preds = logits.argmax(-1)`<br/>` return metric.compute(predictions=preds, references=labels)`                                                                                                                                  |
| `DataCollatorWithPadding`         | `DataCollatorWithPadding(tokenizer, padding=True, max_length=None, pad_to_multiple_of=None)` — Pads dynamically to longest in batch.                                                                                                                                                                                                                                            | `from transformers import DataCollatorWithPadding`<br/>`collator = DataCollatorWithPadding(tokenizer)`                                                                                                                                                                                                                                                                  |
| `DataCollatorForLanguageModeling` | `DataCollatorForLanguageModeling(tokenizer, mlm=True, mlm_probability=0.15)` — For MLM pretraining.                                                                                                                                                                                                                                                                             | `from transformers import DataCollatorForLanguageModeling`<br/>`mlm_collator = DataCollatorForLanguageModeling(tokenizer, mlm=True, mlm_probability=0.15)`                                                                                                                                                                                                              |
| `DataCollatorForSeq2Seq`          | `DataCollatorForSeq2Seq(tokenizer, model=None, padding=True, max_length=None, label_pad_token_id=-100)` — For seq2seq (T5, BART).                                                                                                                                                                                                                                               | `from transformers import DataCollatorForSeq2Seq`<br/>`collator = DataCollatorForSeq2Seq(tokenizer, model=model)`                                                                                                                                                                                                                                                       |
| `trainer.train()`                 | `trainer.train(resume_from_checkpoint=None)` — Run training. Returns `TrainOutput`.                                                                                                                                                                                                                                                                                             | `trainer.train()`<br/>`trainer.train(resume_from_checkpoint="./out/checkpoint-500")`                                                                                                                                                                                                                                                                                    |
| `trainer.evaluate()`              | `trainer.evaluate(eval_dataset=None, metric_key_prefix='eval')` — Returns metrics dict.                                                                                                                                                                                                                                                                                         | `metrics = trainer.evaluate()`<br/>`print(metrics)`                                                                                                                                                                                                                                                                                                                     |
| `trainer.predict()`               | `trainer.predict(test_dataset)` — Returns `PredictionOutput(predictions, label_ids, metrics)`.                                                                                                                                                                                                                                                                                  | `out = trainer.predict(test_ds)`<br/>`preds = out.predictions.argmax(-1)`                                                                                                                                                                                                                                                                                               |
| `trainer.save_model()`            | `trainer.save_model(output_dir=None)` — Save model + tokenizer (if passed) to disk.                                                                                                                                                                                                                                                                                             | `trainer.save_model("./final-model")`                                                                                                                                                                                                                                                                                                                                   |
| Callbacks                         | `EarlyStoppingCallback(early_stopping_patience=1)` etc.                                                                                                                                                                                                                                                                                                                         | `from transformers import EarlyStoppingCallback`<br/>`trainer.add_callback(EarlyStoppingCallback(early_stopping_patience=2))`                                                                                                                                                                                                                                           |

## PEFT integration (LoRA, QLoRA)

| Method                               | Description                                                                                                                                   | Code example                                                                                                                                                                                 |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Install PEFT                         | `pip install peft` — Hugging Face's parameter-efficient fine-tuning library.                                                                  | `pip install peft accelerate bitsandbytes`                                                                                                                                                   |
| `LoraConfig`                         | `LoraConfig(r=8, lora_alpha=16, target_modules=None, lora_dropout=0.05, bias='none', task_type='CAUSAL_LM')`.                                 | `from peft import LoraConfig, get_peft_model, TaskType`<br/>`config = LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj", "v_proj"], lora_dropout=0.05, task_type=TaskType.CAUSAL_LM)` |
| `get_peft_model()`                   | `get_peft_model(model, peft_config, adapter_name='default')` — Wrap a model with LoRA.                                                        | `model = get_peft_model(model, config)`<br/>`model.print_trainable_parameters()`                                                                                                             |
| `prepare_model_for_kbit_training()`  | `prepare_model_for_kbit_training(model, use_gradient_checkpointing=True)` — Required before applying LoRA to a 4-bit / 8-bit quantized model. | `from peft import prepare_model_for_kbit_training`<br/>`model = prepare_model_for_kbit_training(model)`                                                                                      |
| `model.print_trainable_parameters()` | Prints trainable / total params and percentage.                                                                                               | `model.print_trainable_parameters()`<br/>`# trainable: 4,194,304 \|\| all: 6,742,089,728 \|\| trainable%: 0.0622`                                                                            |
| Save / load LoRA adapter             | `model.save_pretrained(path)` saves only the adapter. Load with `PeftModel.from_pretrained(base_model, adapter_path)`.                        | `model.save_pretrained("./lora-adapter")`<br/>`from peft import PeftModel`<br/>`merged = PeftModel.from_pretrained(base, "./lora-adapter")`                                                  |
| Merge adapter into base              | `model.merge_and_unload()` — Combine LoRA weights into base. Returns a standard `nn.Module`.                                                  | `merged_model = model.merge_and_unload()`                                                                                                                                                    |

## Common patterns

| Pattern                              | Code                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| Sentiment classification (zero-code) | `clf = pipeline("sentiment-analysis")`<br/>`result = clf(["I love it!", "Terrible product."])`                                                                                                                                                                                                                                                                                                                                                                                  |
| Quick text generation                | `gen = pipeline("text-generation", model="gpt2")`<br/>`out = gen("Once upon a time", max_new_tokens=50, temperature=0.7, do_sample=True)`                                                                                                                                                                                                                                                                                                                                       |
| Chat with an instruct model          | `tok = AutoTokenizer.from_pretrained(name)`<br/>`model = AutoModelForCausalLM.from_pretrained(name, torch_dtype=torch.bfloat16, device_map="auto")`<br/>`msgs = [{"role": "user", "content": "Explain attention briefly."}]`<br/>`inputs = tok.apply_chat_template(msgs, add_generation_prompt=True, return_tensors="pt").to(model.device)`<br/>`out = model.generate(inputs, max_new_tokens=200)`<br/>`print(tok.decode(out[0, inputs.shape[-1]:], skip_special_tokens=True))` |
| BERT classification fine-tune        | `from transformers import AutoModelForSequenceClassification`<br/>`model = AutoModelForSequenceClassification.from_pretrained("bert-base-uncased", num_labels=3)`<br/>`# tokenize, build dataset, then Trainer().train()`                                                                                                                                                                                                                                                       |
| QLoRA fine-tune (7B model)           | `bnb = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=torch.bfloat16)`<br/>`model = AutoModelForCausalLM.from_pretrained(name, quantization_config=bnb, device_map="auto")`<br/>`model = prepare_model_for_kbit_training(model)`<br/>`model = get_peft_model(model, LoraConfig(r=16, target_modules=["q_proj","v_proj"], task_type="CAUSAL_LM"))`<br/>`# Then Trainer or SFTTrainer (TRL)`                                             |
| Embeddings via sentence-transformers | `from sentence_transformers import SentenceTransformer`<br/>`model = SentenceTransformer("BAAI/bge-small-en-v1.5")`<br/>`embeddings = model.encode(texts, normalize_embeddings=True)`                                                                                                                                                                                                                                                                                           |
| Generate then push to hub            | `model.push_to_hub("username/my-finetuned")`<br/>`tokenizer.push_to_hub("username/my-finetuned")`                                                                                                                                                                                                                                                                                                                                                                               |
| Inference speed-up                   | `model = model.to(torch.bfloat16).to("cuda")`<br/>`model = torch.compile(model) # Pytorch 2+ JIT compile`                                                                                                                                                                                                                                                                                                                                                                       |
| Disable cache for training           | Set `model.config.use_cache = False` before training.                                                                                                                                                                                                                                                                                                                                                                                                                           |     |
| Compute perplexity                   | `loss = model(input_ids=ids, labels=ids).loss`<br/>`perplexity = torch.exp(loss)`                                                                                                                                                                                                                                                                                                                                                                                               |
