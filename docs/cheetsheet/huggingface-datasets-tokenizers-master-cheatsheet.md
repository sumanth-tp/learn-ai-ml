# Hugging Face Datasets and Tokenizers Master Cheatsheet

`datasets` provides streaming-friendly, memory-efficient access to thousands of
public datasets and your own files. `tokenizers` (and `AutoTokenizer` from
`transformers`) is the fast Rust-backed tokenizer library. Together they cover
the entire data pipeline before training.

## Loading datasets

| Method                    | Description                                                                                                                                                                              | Code example                                                                                                            |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `load_dataset()`          | `load_dataset(path, name=None, split=None, data_dir=None, data_files=None, cache_dir=None, streaming=False, num_proc=None, trust_remote_code=False)` — Load from the Hub or local files. | `from datasets import load_dataset`<br/>`ds = load_dataset("imdb")`<br/>`ds = load_dataset("squad", split="train")`     |
| Load specific split       | `load_dataset(path, split='train[:5%]')` — Use slicing syntax like `"train[:1000]"`, `"train[80%:]"`.                                                                                    | `small = load_dataset("imdb", split="train[:1000]")`                                                                    |
| Load multiple splits      | `load_dataset(path, split=['train', 'test'])` — Returns a list aligned with splits.                                                                                                      | `train, test = load_dataset("imdb", split=["train", "test"])`                                                           |
| Load local files          | `load_dataset('csv', data_files=...)` / `'json'` / `'parquet'` / `'text'`.                                                                                                               | `ds = load_dataset("csv", data_files={"train": "train.csv", "test": "test.csv"})`                                       |
| Load JSON-lines           | `load_dataset('json', data_files=path)` — Auto-detects JSON-lines vs JSON-array.                                                                                                         | `ds = load_dataset("json", data_files="logs.jsonl")`                                                                    |
| Load with glob            | Pass list or dict of paths/globs.                                                                                                                                                        | `load_dataset("parquet", data_files="data/shard-*.parquet")`                                                            |
| Stream large datasets     | `load_dataset(..., streaming=True)` — Returns `IterableDataset`. Lazy, no full download.                                                                                                 | `stream = load_dataset("c4", "en", split="train", streaming=True)`<br/>`for example in stream.take(10): print(example)` |
| Load private dataset      | Authenticate with `huggingface_hub.login()` first.                                                                                                                                       | `from huggingface_hub import login`<br/>`login(token="hf_xxx")`<br/>`ds = load_dataset("username/private-data")`        |
| Force reload (skip cache) | `load_dataset(..., download_mode='force_redownload')`.                                                                                                                                   | `ds = load_dataset("imdb", download_mode="force_redownload")`                                                           |

## Dataset structure and access

| Method                    | Description                                                                                               | Code example                                                                                               |
| ------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `Dataset` shape           | A `Dataset` is a columnar Arrow table. Iterate or index by row, slice, or column.                         | `print(ds)`<br/>`print(ds.column_names)`<br/>`print(ds.features)`                                          |
| Row access                | `ds[i]` returns dict; `ds[i:j]` returns dict of lists.                                                    | `print(ds[0])`<br/>`print(ds[0:3])`                                                                        |
| Column access             | `ds["column_name"]` returns the column as a list (lazy slice).                                            | `print(ds["text"][:5])`                                                                                    |
| `ds.features`             | Schema with types: `Value`, `Sequence`, `ClassLabel`, `Image`, `Audio`.                                   | `print(ds.features)`                                                                                       |
| `ds.num_rows` / `len(ds)` | Total number of rows.                                                                                     | `print(len(ds))`                                                                                           |
| `DatasetDict`             | Multi-split container (`{"train": ..., "test": ...}`). Indexable by split name.                           | `ds = load_dataset("imdb") # returns DatasetDict`<br/>`print(ds["train"][0])`                              |
| `ds.shuffle()`            | `ds.shuffle(seed=None, buffer_size=1000, keep_in_memory=False)` — Returns shuffled dataset.               | `ds = ds.shuffle(seed=42)`                                                                                 |
| `ds.select()`             | `ds.select(indices, keep_in_memory=False)` — Pick specific rows by index.                                 | `subset = ds.select(range(1000))`                                                                          |
| `ds.train_test_split()`   | `ds.train_test_split(test_size=None, train_size=None, shuffle=True, seed=None, stratify_by_column=None)`. | `splits = ds.train_test_split(test_size=0.1, seed=42)`<br/>`train, test = splits["train"], splits["test"]` |
| `ds.unique()`             | `ds.unique(column)` — Distinct values in a column. Useful for class lists.                                | `print(ds.unique("label"))`                                                                                |

## Transformation: map, filter, batch

| Method                 | Description                                                                                                                                                              | Code example                                                                                                                                                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ds.map()`             | `ds.map(function, batched=False, batch_size=1000, num_proc=None, remove_columns=None, load_from_cache_file=True, fn_kwargs=None)` — Apply a function row- or batch-wise. | `def add_length(example):`<br/>` example["length"] = len(example["text"])`<br/>` return example`<br/>`ds = ds.map(add_length)`                                                                                                               |
| Batched map (fast)     | `batched=True` — Function receives dict of _lists_. Much faster, especially for tokenization.                                                                            | `def tokenize_batch(batch):`<br/>` return tokenizer(batch["text"], truncation=True, max_length=128)`<br/>`ds = ds.map(tokenize_batch, batched=True, batch_size=1000)`                                                                        |
| `ds.filter()`          | `ds.filter(function, batched=False, num_proc=None, load_from_cache_file=True)` — Keep rows where function returns True.                                                  | `ds = ds.filter(lambda x: len(x["text"]) > 50)`                                                                                                                                                                                              |
| `ds.remove_columns()`  | `ds.remove_columns(column_names)` — Drop columns to save memory.                                                                                                         | `ds = ds.remove_columns(["raw_text", "id"])`                                                                                                                                                                                                 |
| `ds.rename_column()`   | `ds.rename_column(original_name, new_name)`. Plural: `rename_columns({old: new, ...})`.                                                                                  | `ds = ds.rename_column("label", "labels")`                                                                                                                                                                                                   |
| `ds.cast_column()`     | `ds.cast_column(column_name, feature)` — Change a column's type.                                                                                                         | `from datasets import ClassLabel`<br/>`ds = ds.cast_column("label", ClassLabel(names=["neg", "pos"]))`                                                                                                                                       |
| `ds.sort()`            | `ds.sort(column_names, reverse=False, kind='stable')` — Sort by one or more columns.                                                                                     | `ds = ds.sort("length")`                                                                                                                                                                                                                     |
| `ds.flatten()`         | `ds.flatten()` — Flatten nested struct columns.                                                                                                                          | `ds = ds.flatten()`                                                                                                                                                                                                                          |
| Parallel map           | `num_proc=N` — Multi-process map. Speeds up tokenization significantly.                                                                                                  | `ds = ds.map(tokenize_batch, batched=True, num_proc=8)`                                                                                                                                                                                      |
| Custom features schema | Define explicit types when creating from Python data.                                                                                                                    | `from datasets import Dataset, Features, Value, ClassLabel`<br/>`features = Features({"text": Value("string"), "label": ClassLabel(names=["neg", "pos"])})`<br/>`ds = Dataset.from_dict({"text": [...], "label": [...]}, features=features)` |

## Format conversion and PyTorch integration

| Method                   | Description                                                                                                          | Code example                                                                                                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `ds.set_format()`        | `ds.set_format(type=None, columns=None, output_all_columns=False)` — Return tensors/numpy/pandas from `__getitem__`. | `ds.set_format(type="torch", columns=["input_ids", "attention_mask", "labels"])`<br/>`print(ds[0]["input_ids"].dtype) # torch.int64` |
| `ds.with_format()`       | Same as `set_format` but returns a new view (non-mutating).                                                          | `ds_torch = ds.with_format("torch")`                                                                                                 |
| `ds.reset_format()`      | Reset back to Python lists/dicts.                                                                                    | `ds.reset_format()`                                                                                                                  |
| Convert to pandas        | `ds.to_pandas(batch_size=None, batched=False)` — Returns DataFrame (or iterator if `batched=True`).                  | `df = ds.to_pandas()`                                                                                                                |
| Convert to list          | `ds.to_list()` — List of dicts. Materializes the whole dataset.                                                      | `rows = ds.to_list()`                                                                                                                |
| Build PyTorch DataLoader | `from torch.utils.data import DataLoader`. After `set_format('torch')`, dataset is DataLoader-compatible.            | `dl = DataLoader(ds, batch_size=32, shuffle=True, collate_fn=collator)`                                                              |
| Create from a generator  | `Dataset.from_generator(generator, gen_kwargs=None, features=None)`.                                                 | `def gen():`<br/>` for i in range(1000): yield {"x": i, "y": i*2}`<br/>`ds = Dataset.from_generator(gen)`                            |
| Create from a dict       | `Dataset.from_dict(mapping, features=None)`.                                                                         | `ds = Dataset.from_dict({"text": [...], "label": [...]})`                                                                            |
| Create from pandas       | `Dataset.from_pandas(df, preserve_index=False)`.                                                                     | `ds = Dataset.from_pandas(df)`                                                                                                       |

## Saving and sharing

| Method                                       | Description                                                                                               | Code example                                                                    |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `ds.save_to_disk()`                          | `ds.save_to_disk(dataset_path, num_proc=None)` — Save the Arrow files. Faster reload than `load_dataset`. | `ds.save_to_disk("./my_dataset")`                                               |
| `load_from_disk()`                           | `load_from_disk(dataset_path)` — Load a previously saved Arrow dataset.                                   | `from datasets import load_from_disk`<br/>`ds = load_from_disk("./my_dataset")` |
| `ds.to_parquet()` / `to_csv()` / `to_json()` | `ds.to_parquet(path)` / `ds.to_csv(path)` / `ds.to_json(path)`.                                           | `ds.to_parquet("data.parquet")`                                                 |
| Push to Hub                                  | `ds.push_to_hub(repo_id, private=False, token=None, split=None)` — Upload as a Hub dataset.               | `ds.push_to_hub("username/my-dataset")`                                         |
| `DatasetDict.push_to_hub()`                  | Same on a multi-split dict — uploads all splits as one Hub dataset.                                       | `ds_dict.push_to_hub("username/my-dataset")`                                    |

## Streaming datasets (IterableDataset)

| Method                       | Description                                                                                                           | Code example                                                                                                           |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `streaming=True`             | Returns `IterableDataset` — lazy, no full download.                                                                   | `ds = load_dataset("c4", "en", split="train", streaming=True)`                                                         |
| `.take()` / `.skip()`        | `.take(n)` / `.skip(n)` — First N / skip first N.                                                                     | `first_100 = ds.take(100)`<br/>`rest = ds.skip(100)`                                                                   |
| `.shuffle()` (streaming)     | `.shuffle(seed=None, buffer_size=10_000)` — Approximate shuffle via reservoir buffer.                                 | `ds = ds.shuffle(seed=42, buffer_size=10_000)`                                                                         |
| Streaming map / filter       | Same API as `Dataset`; lazy.                                                                                          | `ds = ds.map(tokenize_batch, batched=True)`                                                                            |
| Interleave / concat datasets | `interleave_datasets(datasets, probabilities=None, stopping_strategy='first_exhausted')` for mixing multiple corpora. | `from datasets import interleave_datasets`<br/>`mixed = interleave_datasets([ds_en, ds_de], probabilities=[0.7, 0.3])` |

## Evaluate metrics

| Method             | Description                                                                                             | Code example                                                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Install            | `pip install evaluate`.                                                                                 | `pip install evaluate`                                                                                                                |
| `evaluate.load()`  | `evaluate.load(path, config_name=None, module_type=None, process_id=0, num_process=1)` — Load a metric. | `import evaluate`<br/>`metric = evaluate.load("accuracy")`                                                                            |
| `metric.compute()` | `metric.compute(predictions=..., references=..., **kwargs)` — Compute the score.                        | `metric.compute(predictions=preds, references=labels)`                                                                                |
| `.add_batch()`     | `metric.add_batch(predictions=..., references=...)` — Accumulate without computing.                     | `for batch in loader: metric.add_batch(predictions=..., references=...)`<br/>`metric.compute()`                                       |
| Common metrics     | `"accuracy"`, `"f1"`, `"precision"`, `"recall"`, `"rouge"`, `"bleu"`, `"bertscore"`, `"perplexity"`.    | `rouge = evaluate.load("rouge")`<br/>`rouge.compute(predictions=summaries, references=refs)`                                          |
| Combine metrics    | `evaluate.combine([m1, m2, ...])` — Compute multiple at once.                                           | `combined = evaluate.combine(["accuracy", "f1", "precision", "recall"])`<br/>`combined.compute(predictions=preds, references=labels)` |

## Tokenizers (the Rust library, via `transformers.AutoTokenizer`)

| Method                       | Description                                                                                                                                                                                 | Code example                                                                                              |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Fast vs slow tokenizers      | `AutoTokenizer.from_pretrained(name, use_fast=True)` — Fast (Rust) tokenizers are 10-100× faster and support batch parallelism.                                                             | `tok = AutoTokenizer.from_pretrained("bert-base-uncased", use_fast=True)`                                 |
| `tokenizer.is_fast`          | Attribute. True if Rust-backed.                                                                                                                                                             | `print(tok.is_fast)`                                                                                      |
| Tokenize                     | `tokenizer(text, add_special_tokens=True, padding=False, truncation=False, max_length=None, return_tensors=None, return_offsets_mapping=False, return_overflowing_tokens=False, stride=0)`. | `enc = tok("Hello world", padding="max_length", max_length=16, return_tensors="pt")`                      |
| Padding strategies           | `padding=True` (longest in batch) / `'max_length'` (to `max_length`) / `'do_not_pad'` (no padding).                                                                                         | `tok(texts, padding=True, return_tensors="pt")`                                                           |
| Truncation strategies        | `truncation=True` (longest first) / `'only_first'` / `'only_second'` / `'longest_first'`.                                                                                                   | `tok(query, context, truncation="only_second", max_length=384)`                                           |
| Offset mapping               | `return_offsets_mapping=True` — Returns `(start, end)` char indices per token. Essential for QA span extraction.                                                                            | `enc = tok(text, return_offsets_mapping=True, return_tensors="pt")`<br/>`print(enc["offset_mapping"][0])` |
| Word IDs (fast only)         | `enc.word_ids(batch_index=0)` — Map each token to its original word index. For NER alignment.                                                                                               | `enc = tok(words, is_split_into_words=True, return_tensors="pt")`<br/>`print(enc.word_ids(0))`            |
| `is_split_into_words`        | Pass `True` if input is already word-tokenized (a list of words per example).                                                                                                               | `tok([["The", "cat", "sat"]], is_split_into_words=True)`                                                  |
| Sliding window for long docs | `return_overflowing_tokens=True, stride=128` — Split long texts into overlapping chunks.                                                                                                    | `enc = tok(long_text, max_length=512, truncation=True, return_overflowing_tokens=True, stride=128)`       |
| Decode                       | `tokenizer.decode(token_ids, skip_special_tokens=False, clean_up_tokenization_spaces=True)`.                                                                                                | `print(tok.decode(enc["input_ids"][0], skip_special_tokens=True))`                                        |
| Convert tokens / IDs         | `tokenizer.convert_tokens_to_ids(tokens)` / `tokenizer.convert_ids_to_tokens(ids, skip_special_tokens=False)`.                                                                              | `print(tok.convert_ids_to_tokens([101, 7592, 2088, 102]))`                                                |

## Training a custom tokenizer (Rust `tokenizers` library)

| Method                         | Description                                                                                                   | Code example                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Install                        | `pip install tokenizers` (already a dep of `transformers`).                                                   | `pip install tokenizers`                                                                                                                                                                                                                                                                                                                                                            |
| BPE tokenizer                  | `Tokenizer(BPE(unk_token='[UNK]'))` + `BpeTrainer(vocab_size, special_tokens, min_frequency)`.                | `from tokenizers import Tokenizer`<br/>`from tokenizers.models import BPE`<br/>`from tokenizers.trainers import BpeTrainer`<br/>`from tokenizers.pre_tokenizers import Whitespace`<br/>`tok = Tokenizer(BPE(unk_token="[UNK]"))`<br/>`tok.pre_tokenizer = Whitespace()`<br/>`trainer = BpeTrainer(vocab_size=30000, special_tokens=["[PAD]", "[UNK]", "[CLS]", "[SEP]", "[MASK]"])` |
| WordPiece tokenizer            | `Tokenizer(WordPiece(unk_token='[UNK]'))` + `WordPieceTrainer(...)`.                                          | `from tokenizers.models import WordPiece`<br/>`from tokenizers.trainers import WordPieceTrainer`<br/>`tok = Tokenizer(WordPiece(unk_token="[UNK]"))`                                                                                                                                                                                                                                |
| Unigram tokenizer              | `Tokenizer(Unigram())` + `UnigramTrainer(...)`. Used by T5, ALBERT, XLNet.                                    | `from tokenizers.models import Unigram`<br/>`tok = Tokenizer(Unigram())`                                                                                                                                                                                                                                                                                                            |
| Train                          | `tok.train(files, trainer)` / `tok.train_from_iterator(iterator, trainer, length=None)`.                      | `tok.train(["corpus.txt"], trainer)`<br/>`# or`<br/>`tok.train_from_iterator(text_generator(), trainer)`                                                                                                                                                                                                                                                                            |
| Pre-tokenizer                  | Sets word-boundary rules. Options: `Whitespace()`, `ByteLevel(add_prefix_space=False)`, `BertPreTokenizer()`. | `tok.pre_tokenizer = ByteLevel(add_prefix_space=False)`                                                                                                                                                                                                                                                                                                                             |
| Decoder                        | Sets how to recombine tokens to text. `ByteLevel()`, `WordPiece(prefix='##')`.                                | `tok.decoder = decoders.ByteLevel()`                                                                                                                                                                                                                                                                                                                                                |
| Save / load                    | `tok.save(path)` / `Tokenizer.from_file(path)`.                                                               | `tok.save("./tokenizer.json")`<br/>`tok = Tokenizer.from_file("./tokenizer.json")`                                                                                                                                                                                                                                                                                                  |
| Wrap as Hugging Face tokenizer | `PreTrainedTokenizerFast(tokenizer_object=tok, ...)` — Use the trained Rust tokenizer in `transformers`.      | `from transformers import PreTrainedTokenizerFast`<br/>`hf_tok = PreTrainedTokenizerFast(tokenizer_object=tok, unk_token="[UNK]", pad_token="[PAD]")`                                                                                                                                                                                                                               |

## Common patterns

| Pattern                             | Code                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tokenize a dataset                  | `def tokenize_fn(batch):`<br/>` return tokenizer(batch["text"], truncation=True, max_length=512)`<br/>`tokenized = ds.map(tokenize_fn, batched=True, remove_columns=["text"])`                                                                                                                                                                                                                             |
| Prep for Trainer (set torch format) | `tokenized = tokenized.with_format("torch")`                                                                                                                                                                                                                                                                                                                                                               |
| Group documents for LM pretraining  | `def group_texts(examples):`<br/>` block_size = 1024`<br/>` concat = sum(examples["input_ids"], [])`<br/>` total = (len(concat) // block_size) * block_size`<br/>` result = {`<br/>` "input_ids": [concat[i:i+block_size] for i in range(0, total, block_size)]`<br/>` }`<br/>` result["labels"] = result["input_ids"].copy()`<br/>` return result`<br/>`lm_ds = tokenized.map(group_texts, batched=True)` |
| QA preprocessing with offsets       | `def prep(batch):`<br/>` enc = tokenizer(batch["question"], batch["context"], truncation="only_second", max_length=384, stride=128, return_overflowing_tokens=True, return_offsets_mapping=True)`<br/>` # then map answer char-positions to token-positions via offset_mapping`<br/>` return enc`                                                                                                          |
| NER alignment                       | `def align_labels(batch):`<br/>` enc = tokenizer(batch["tokens"], is_split_into_words=True, truncation=True)`<br/>` labels = []`<br/>` for i, label in enumerate(batch["ner_tags"]):`<br/>` word_ids = enc.word_ids(batch_index=i)`<br/>` labels.append([-100 if w is None else label[w] for w in word_ids])`<br/>` enc["labels"] = labels`<br/>` return enc`                                              |
| Streaming pretraining feed          | `stream = load_dataset("c4", "en", split="train", streaming=True)`<br/>`stream = stream.shuffle(seed=42, buffer_size=10_000).map(tokenize_fn, batched=True)`<br/>`# pass directly to Trainer or DataLoader`                                                                                                                                                                                                |
| Quick metric for classification     | `import evaluate`<br/>`acc = evaluate.load("accuracy")`<br/>`acc.compute(predictions=preds, references=labels)`                                                                                                                                                                                                                                                                                            |
| Train custom BPE on local corpus    | `from tokenizers import Tokenizer, models, trainers, pre_tokenizers`<br/>`tok = Tokenizer(models.BPE())`<br/>`tok.pre_tokenizer = pre_tokenizers.ByteLevel()`<br/>`trainer = trainers.BpeTrainer(vocab_size=50_000, special_tokens=["<\|endoftext\|>"])`<br/>`tok.train(["corpus.txt"], trainer)`<br/>`tok.save("custom-bpe.json")`                                                                        |
