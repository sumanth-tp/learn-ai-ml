# Matplotlib and Seaborn Master Cheatsheet

Matplotlib is the foundational plotting library; seaborn is a high-level wrapper
that produces statistical plots in one line. Most ML notebooks use both —
matplotlib for fine control, seaborn for fast EDA.

## Setup and figure basics

| Method                     | Description                                                                                                                                   | Code example                                                                                         |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Import convention          | Standard aliases used in every tutorial. `sns.set_theme(context='notebook', style='whitegrid', palette='deep', font='sans-serif')`.           | `import matplotlib.pyplot as plt`<br/>`import seaborn as sns`<br/>`sns.set_theme(style="whitegrid")` |
| `plt.figure()`             | `plt.figure(figsize=None, dpi=None, facecolor=None, edgecolor=None, tight_layout=None)` — Create a new figure.                                | `fig = plt.figure(figsize=(10, 6), dpi=100)`                                                         |
| `plt.subplots()`           | `plt.subplots(nrows=1, ncols=1, sharex=False, sharey=False, figsize=None, gridspec_kw=None)` — Returns (fig, ax). The recommended modern API. | `fig, ax = plt.subplots(figsize=(8, 5))`<br/>`ax.plot([1, 2, 3], [1, 4, 9])`                         |
| `plt.subplots(rows, cols)` | Same call as above with `nrows`/`ncols > 1` — returns a 2D array of axes.                                                                     | `fig, axes = plt.subplots(2, 2, figsize=(10, 8))`<br/>`axes[0, 0].plot([1, 2, 3])`                   |
| `plt.tight_layout()`       | `plt.tight_layout(pad=1.08, h_pad=None, w_pad=None, rect=None)` — Auto-adjust spacing between subplots.                                       | `plt.tight_layout()`                                                                                 |
| `plt.savefig()`            | `plt.savefig(fname, dpi=None, bbox_inches=None, pad_inches=0.1, transparent=False, format=None)` — Save figure.                               | `plt.savefig("output.png", dpi=300, bbox_inches="tight")`                                            |
| `plt.show()`               | `plt.show(block=None)` — Display the figure (mainly for scripts; notebooks auto-display).                                                     | `plt.show()`                                                                                         |
| `plt.close()`              | `plt.close(fig=None)` — Close a figure to free memory. Pass `'all'` to close everything.                                                      | `plt.close(fig)`                                                                                     |

## Line and scatter plots

| Method            | Description                                                                                                            | Code example                                                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `ax.plot()`       | `ax.plot(x, y, fmt=None, color=None, linestyle='-', linewidth=None, marker=None, label=None, alpha=None)` — Line plot. | `import numpy as np`<br/>`x = np.linspace(0, 10, 100)`<br/>`ax.plot(x, np.sin(x), label="sin", linewidth=2, color="tab:blue")` |
| Multiple lines    | Call `ax.plot()` multiple times on the same axes.                                                                      | `ax.plot(x, np.sin(x), label="sin")`<br/>`ax.plot(x, np.cos(x), label="cos")`<br/>`ax.legend()`                                |
| Line styles       | `linestyle=` supports `-`, `--`, `:`, `-.`. Color shorthand: `'r--'`.                                                  | `ax.plot(x, y, linestyle="--", color="red")`                                                                                   |
| `ax.scatter()`    | `ax.scatter(x, y, s=None, c=None, marker=None, cmap=None, alpha=None, edgecolors=None, label=None)` — Scatter plot.    | `ax.scatter(x, y, s=20, c=labels, cmap="viridis", alpha=0.7)`                                                                  |
| Annotated scatter | `ax.annotate(text, xy, xytext=None, arrowprops=None, fontsize=None)` — Add text labels to specific points.             | `for i, name in enumerate(names):`<br/>` ax.annotate(name, (x[i], y[i]), fontsize=8)`                                          |
| Error bars        | `ax.errorbar(x, y, yerr=None, xerr=None, fmt='', capsize=None, label=None)` — For plots with uncertainty.              | `ax.errorbar(x, y, yerr=stderr, fmt="o", capsize=4)`                                                                           |
| Filled regions    | `ax.fill_between(x, y1, y2=0, where=None, alpha=None, color=None)` — For confidence intervals or shaded ranges.        | `ax.plot(x, mean)`<br/>`ax.fill_between(x, mean - std, mean + std, alpha=0.2)`                                                 |

## Bar, histogram, and distribution plots

| Method            | Description                                                                                                                             | Code example                                                                                                                                            |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ax.bar()`        | `ax.bar(x, height, width=0.8, bottom=None, align='center', color=None, label=None)` — Vertical bar plot.                                | `categories = ["A", "B", "C"]`<br/>`values = [10, 25, 18]`<br/>`ax.bar(categories, values, color="steelblue")`                                          |
| `ax.barh()`       | `ax.barh(y, width, height=0.8, left=None, color=None, label=None)` — Horizontal bar plot.                                               | `ax.barh(categories, values)`                                                                                                                           |
| Stacked bars      | Pass `bottom=` (or `left=`) on the second bar call.                                                                                     | `ax.bar(x, group1)`<br/>`ax.bar(x, group2, bottom=group1)`                                                                                              |
| Grouped bars      | Offset x positions by bar width.                                                                                                        | `width = 0.35`<br/>`x = np.arange(len(labels))`<br/>`ax.bar(x - width/2, group1, width, label="A")`<br/>`ax.bar(x + width/2, group2, width, label="B")` |
| `ax.hist()`       | `ax.hist(x, bins=None, range=None, density=False, weights=None, cumulative=False, color=None, edgecolor=None, alpha=None)` — Histogram. | `ax.hist(data, bins=30, color="tab:orange", edgecolor="white", alpha=0.7)`                                                                              |
| `ax.boxplot()`    | `ax.boxplot(x, notch=False, labels=None, showmeans=False, vert=True)` — Box plot for distribution comparison.                           | `ax.boxplot([group1, group2, group3], labels=["A", "B", "C"])`                                                                                          |
| `ax.violinplot()` | `ax.violinplot(dataset, showmeans=False, showmedians=False, showextrema=True)` — Distribution shape + box info.                         | `ax.violinplot([group1, group2, group3], showmeans=True)`                                                                                               |

## Customization: labels, ticks, legends

| Method                                | Description                                                                                                  | Code example                                                                        |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| `ax.set_title()`                      | `ax.set_title(label, fontsize=None, color=None, loc='center', pad=None)` — Plot title.                       | `ax.set_title("Model loss over epochs", fontsize=14)`                               |
| `ax.set_xlabel()` / `ax.set_ylabel()` | `ax.set_xlabel(xlabel, fontsize=None, labelpad=None)` / `ax.set_ylabel(ylabel, ...)` — Axis labels.          | `ax.set_xlabel("Epoch")`<br/>`ax.set_ylabel("Loss")`                                |
| `ax.set_xlim()` / `ax.set_ylim()`     | `ax.set_xlim(left=None, right=None)` / `ax.set_ylim(bottom=None, top=None)` — Set axis ranges.               | `ax.set_xlim(0, 100)`<br/>`ax.set_ylim(0, 1)`                                       |
| `ax.set_xticks()` / `ax.set_yticks()` | `ax.set_xticks(ticks, labels=None, minor=False)` / `ax.set_yticks(ticks, ...)` — Explicit tick locations.    | `ax.set_xticks([0, 0.5, 1.0])`                                                      |
| `ax.set_xticklabels()`                | `ax.set_xticklabels(labels, rotation=None, fontsize=None, ha=None)` — Custom tick label strings.             | `ax.set_xticklabels(["small", "med", "large"], rotation=45)`                        |
| `ax.legend()`                         | `ax.legend(loc='best', bbox_to_anchor=None, ncol=1, frameon=True, fontsize=None, title=None)` — Show legend. | `ax.legend(loc="upper right", frameon=False)`                                       |
| `ax.grid()`                           | `ax.grid(visible=None, which='major', axis='both', alpha=None, linestyle='-')` — Toggle gridlines.           | `ax.grid(True, alpha=0.3, linestyle="--")`                                          |
| `ax.spines`                           | `ax.spines[side].set_visible(False)` — Remove plot borders for cleaner look.                                 | `for side in ["top", "right"]:`<br/>` ax.spines[side].set_visible(False)`           |
| Log scale                             | `ax.set_yscale(scale)` / `ax.set_xscale(scale)` where `scale` is `'log'`, `'linear'`, `'symlog'`.            | `ax.set_yscale("log")`                                                              |
| Twin axes                             | `ax.twinx()` (shares x) / `ax.twiny()` (shares y) — Returns a new axis.                                      | `ax2 = ax.twinx()`<br/>`ax2.plot(x, other_metric, color="red")`                     |
| Annotations                           | `ax.annotate(text, xy, xytext=None, arrowprops=None)` — Arrow-pointing text for callouts.                    | `ax.annotate("peak", xy=(5, 1), xytext=(7, 0.8), arrowprops=dict(arrowstyle="->"))` |

## Colors, colormaps, and styles

| Method             | Description                                                                                                                   | Code example                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Tableau colors     | `color="tab:blue"` etc. Default categorical palette — accessible and consistent.                                              | `ax.plot(x, y, color="tab:blue") # tab:blue, tab:orange, tab:green, ...`                    |
| `cmap=` argument   | Sequential (`"viridis"`, `"plasma"`), diverging (`"coolwarm"`, `"RdBu_r"`), categorical (`"tab10"`).                          | `ax.scatter(x, y, c=values, cmap="viridis")`                                                |
| `plt.colorbar()`   | `plt.colorbar(mappable, ax=None, label=None, shrink=1.0)` — Color legend for `scatter`/`imshow`/`contour`.                    | `sc = ax.scatter(x, y, c=z, cmap="viridis")`<br/>`plt.colorbar(sc, ax=ax, label="density")` |
| Plot styles        | `plt.style.use(style)` — One-line aesthetic preset: `"seaborn-v0_8"`, `"ggplot"`, `"fivethirtyeight"`.                        | `plt.style.use("seaborn-v0_8-darkgrid")`                                                    |
| Seaborn themes     | `sns.set_theme(context='notebook', style='whitegrid', palette='deep', font_scale=1.0)` — Higher-level than matplotlib styles. | `sns.set_theme(style="whitegrid", palette="deep", context="notebook")`                      |
| Custom color cycle | `ax.set_prop_cycle(cycler)` — Override default line color rotation.                                                           | `from cycler import cycler`<br/>`ax.set_prop_cycle(cycler(color=["#1f77b4", "#ff7f0e"]))`   |
| RGB / hex          | `color="#1f77b4"` or `color=(r, g, b)` — Use hex codes for brand colors.                                                      | `ax.plot(x, y, color="#1f77b4")`                                                            |

## Subplots and layout

| Method                        | Description                                                                                                     | Code example                                                                                                                                                 |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Iterating over axes           | `axes.flat` flattens the 2D axes array.                                                                         | `fig, axes = plt.subplots(2, 3, figsize=(15, 8))`<br/>`for ax, col in zip(axes.flat, df.columns):`<br/>` ax.hist(df[col], bins=20)`<br/>` ax.set_title(col)` |
| `sharex=True` / `sharey=True` | Args to `plt.subplots()` — Subplots share axes (same scale across panels).                                      | `fig, axes = plt.subplots(2, 2, sharex=True, sharey=True)`                                                                                                   |
| `gridspec_kw`                 | `plt.subplots(..., gridspec_kw={'width_ratios': [...], 'height_ratios': [...]})` — Different-sized subplots.    | `fig, (ax1, ax2) = plt.subplots(1, 2, gridspec_kw={"width_ratios": [3, 1]})`                                                                                 |
| `fig.suptitle()`              | `fig.suptitle(t, fontsize=None, x=0.5, y=0.98)` — Title across all subplots.                                    | `fig.suptitle("Per-feature distributions", fontsize=16)`                                                                                                     |
| `fig.text()`                  | `fig.text(x, y, s, ha='left', va='baseline', fontsize=None)` — Free-floating text in figure coordinates.        | `fig.text(0.5, 0.01, "Source: training set, N=10,000", ha="center")`                                                                                         |
| `plt.subplots_adjust()`       | `plt.subplots_adjust(left=None, bottom=None, right=None, top=None, wspace=None, hspace=None)` — Manual spacing. | `plt.subplots_adjust(hspace=0.4, wspace=0.3)`                                                                                                                |
| Twin axes (`ax.twinx`)        | `ax.twinx()` — Same x, different y for plotting two metrics.                                                    | `ax2 = ax.twinx()`<br/>`ax2.plot(epochs, lr, color="gray", linestyle="--")`<br/>`ax2.set_ylabel("Learning rate")`                                            |
| Inset axes                    | `inset_axes(parent_ax, width, height, loc)` — Mini-plot inside a main plot.                                     | `from mpl_toolkits.axes_grid1.inset_locator import inset_axes`<br/>`inset = inset_axes(ax, width="30%", height="30%", loc="upper right")`                    |

## ML-specific plotting

| Plot                             | Use case                                                                                                                                                        | Code example                                                                                                                                                                                                                 |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Loss curves                      | Show training and validation loss over epochs.                                                                                                                  | `ax.plot(history["epoch"], history["train_loss"], label="train")`<br/>`ax.plot(history["epoch"], history["val_loss"], label="val")`<br/>`ax.set_xlabel("Epoch"); ax.set_ylabel("Loss"); ax.legend()`                         |
| Confusion matrix                 | `from sklearn.metrics import confusion_matrix`<br/>`confusion_matrix(y_true, y_pred, labels=None, normalize=None)` returns the matrix. Plot with `sns.heatmap`. | `cm = confusion_matrix(y_true, y_pred)`<br/>`sns.heatmap(cm, annot=True, fmt="d", cmap="Blues", xticklabels=labels, yticklabels=labels)`                                                                                     |
| ROC curve                        | `roc_curve(y_true, y_score, pos_label=None, drop_intermediate=True)` returns (fpr, tpr, thresholds).                                                            | `from sklearn.metrics import roc_curve, auc`<br/>`fpr, tpr, _ = roc_curve(y_true, y_score)`<br/>`ax.plot(fpr, tpr, label=f"AUC = {auc(fpr, tpr):.3f}")`<br/>`ax.plot([0, 1], [0, 1], linestyle="--", color="gray")`          |
| Precision-recall curve           | `precision_recall_curve(y_true, probas_pred, pos_label=None)` returns (precision, recall, thresholds).                                                          | `from sklearn.metrics import precision_recall_curve`<br/>`p, r, _ = precision_recall_curve(y_true, y_score)`<br/>`ax.plot(r, p)`                                                                                             |
| Feature importance               | Plot via `pd.Series(values, index=names).sort_values().plot(kind="barh")`.                                                                                      | `importances = pd.Series(model.feature_importances_, index=feature_names)`<br/>`importances.sort_values().plot(kind="barh", ax=ax)`                                                                                          |
| Residual plot                    | `ax.scatter(y_pred, y_true - y_pred)` plus `ax.axhline(0)` for the zero line.                                                                                   | `residuals = y_true - y_pred`<br/>`ax.scatter(y_pred, residuals, alpha=0.5)`<br/>`ax.axhline(0, color="red")`                                                                                                                |
| Calibration plot                 | `calibration_curve(y_true, y_prob, n_bins=10, strategy='uniform')` returns (prob_true, prob_pred).                                                              | `from sklearn.calibration import calibration_curve`<br/>`prob_true, prob_pred = calibration_curve(y_true, y_proba, n_bins=10)`<br/>`ax.plot(prob_pred, prob_true, marker="o")`<br/>`ax.plot([0, 1], [0, 1], linestyle="--")` |
| Attention heatmap (Transformers) | `sns.heatmap(attn_matrix, xticklabels=..., yticklabels=..., cmap='viridis')`.                                                                                   | `sns.heatmap(attn[head], xticklabels=tokens, yticklabels=tokens, cmap="viridis", cbar=True)`                                                                                                                                 |
| Distribution comparison          | `ax.hist([y_true, y_pred], bins=N, label=[...])` — Side-by-side histogram of two distributions.                                                                 | `ax.hist([y_true, y_pred], bins=30, label=["true", "pred"], alpha=0.7)`<br/>`ax.legend()`                                                                                                                                    |

## Common patterns

| Pattern                                 | Code                                                                                                                                                                                                                                                 |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| EDA: histograms for all numeric columns | `num_cols = df.select_dtypes("number").columns`<br/>`fig, axes = plt.subplots(2, 3, figsize=(15, 8))`<br/>`for ax, col in zip(axes.flat, num_cols):`<br/>` sns.histplot(df[col], kde=True, ax=ax)`<br/>` ax.set_title(col)`<br/>`plt.tight_layout()` |
| Correlation heatmap                     | `sns.heatmap(df.corr(numeric_only=True), annot=True, fmt=".2f", cmap="coolwarm", center=0, square=True)`                                                                                                                                             |
| Side-by-side train/val loss             | `fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5), sharey=True)`<br/>`ax1.plot(history["train_loss"])`<br/>`ax2.plot(history["val_loss"])`                                                                                                       |
| Save grid of model outputs              | `fig, axes = plt.subplots(4, 4, figsize=(10, 10))`<br/>`for ax, img in zip(axes.flat, batch):`<br/>` ax.imshow(img.permute(1, 2, 0))`<br/>` ax.axis("off")`                                                                                          |
| Image grid with predicted labels        | `for ax, (img, pred, true) in zip(axes.flat, samples):`<br/>` ax.imshow(img)`<br/>` color = "green" if pred == true else "red"`<br/>` ax.set_title(f"P:{pred} T:{true}", color=color)`<br/>` ax.axis("off")`                                         |
| 2D embedding visualization              | `sns.scatterplot(x=emb[:, 0], y=emb[:, 1], hue=labels, palette="tab10", s=10, ax=ax)`                                                                                                                                                                |
| Box plot of metric across folds         | `sns.boxplot(data=results, x="model", y="accuracy")`                                                                                                                                                                                                 |
| Animated training progress              | `from matplotlib.animation import FuncAnimation`<br/>`def update(frame):`<br/>` line.set_data(epochs[:frame], losses[:frame])`<br/>`anim = FuncAnimation(fig, update, frames=len(epochs))`                                                           |
