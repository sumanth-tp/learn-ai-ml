# Scikit-learn Master Cheatsheet

Scikit-learn is the standard library for classical machine learning in Python.
Master the `fit`/`predict`/`transform` API, pipelines, cross-validation, and
metrics — these patterns apply to nearly every ML problem before deep learning.

## Data loading and splitting

| Method                                  | Description                                                                                                                                 | Code example                                                                                                                                                                            |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `train_test_split()`                    | `train_test_split(*arrays, test_size=None, train_size=None, random_state=None, shuffle=True, stratify=None)` — Random train/test partition. | `from sklearn.model_selection import train_test_split`<br/>`X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)`                      |
| `stratify=y`                            | Argument of `train_test_split` — Preserves class proportions in train/test. Critical for imbalanced classification.                         | `train_test_split(X, y, stratify=y, test_size=0.2)`                                                                                                                                     |
| `KFold` / `StratifiedKFold`             | `KFold(n_splits=5, shuffle=False, random_state=None)` / `StratifiedKFold(n_splits=5, shuffle=False, random_state=None)`.                    | `from sklearn.model_selection import StratifiedKFold`<br/>`skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=0)`<br/>`for train_idx, val_idx in skf.split(X, y):`<br/>` ...` |
| `TimeSeriesSplit`                       | `TimeSeriesSplit(n_splits=5, max_train_size=None, test_size=None, gap=0)` — Time-ordered CV.                                                | `from sklearn.model_selection import TimeSeriesSplit`<br/>`tscv = TimeSeriesSplit(n_splits=5)`                                                                                          |
| `GroupKFold`                            | `GroupKFold(n_splits=5)` — Don't let same group appear in train and test. Pass `groups=` to `.split()`.                                     | `from sklearn.model_selection import GroupKFold`<br/>`gkf = GroupKFold(n_splits=5)`<br/>`gkf.split(X, y, groups=df["user_id"])`                                                         |
| `load_iris()` / `make_classification()` | `load_iris(return_X_y=False, as_frame=False)` / `make_classification(n_samples=100, n_features=20, n_classes=2, ...)`.                      | `from sklearn.datasets import load_iris, make_classification`<br/>`X, y = load_iris(return_X_y=True)`                                                                                   |

## Preprocessing

| Method                           | Description                                                                                                                                   | Code example                                                                                                                                                                           |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `StandardScaler`                 | `StandardScaler(copy=True, with_mean=True, with_std=True)` — Zero-mean, unit-variance scaling.                                                | `from sklearn.preprocessing import StandardScaler`<br/>`scaler = StandardScaler()`<br/>`X_train_scaled = scaler.fit_transform(X_train)`<br/>`X_test_scaled = scaler.transform(X_test)` |
| `MinMaxScaler`                   | `MinMaxScaler(feature_range=(0, 1), copy=True)` — Scale to a range. | `RobustScaler`                   | `RobustScaler(with_centering=True, with_scaling=True, quantile_range=(25.0, 75.0))` — Robust to outliers (uses median and IQR).               | `from sklearn.preprocessing import RobustScaler`<br/>`rs = RobustScaler()`                                                                                                             |

| `OrdinalEncoder`                 | `OrdinalEncoder(categories='auto', dtype=np.float64, handle_unknown='error')` — Integer-encode (for ordinal features only).                   | `from sklearn.preprocessing import OrdinalEncoder`<br/>`oe = OrdinalEncoder(categories=[["low", "med", "high"]])`                                                                      |

| `Binarizer` / `KBinsDiscretizer` | `Binarizer(threshold=0.0)` / `KBinsDiscretizer(n_bins=5, encode='onehot', strategy='quantile')`.                                              | `from sklearn.preprocessing import KBinsDiscretizer`<br/>`kb = KBinsDiscretizer(n_bins=10, encode="ordinal", strategy="quantile")`                                                     |
| `FunctionTransformer`            | `FunctionTransformer(func=None, inverse_func=None, validate=False, check_inverse=True)` — Wrap any function as a preprocessor.                | `from sklearn.preprocessing import FunctionTransformer`<br/>`log_tf = FunctionTransformer(np.log1p)`                                                                                   |

## Pipelines and ColumnTransformer

| Method                     | Description                                                                                                                                                        | Code example                                                                                                                                                                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Pipeline`                 | `Pipeline(steps, memory=None, verbose=False)` — Chain preprocessing + final estimator. Prevents data leakage.                                                      | `from sklearn.pipeline import Pipeline`<br/>`from sklearn.preprocessing import StandardScaler`<br/>`from sklearn.linear_model import LogisticRegression`<br/>`pipe = Pipeline([("scaler", StandardScaler()), ("clf", LogisticRegression())])`<br/>`pipe.fit(X_train, y_train)` |
| `make_pipeline()`          | `make_pipeline(*steps, memory=None, verbose=False)` — Shortcut; auto-names steps.                                                                                  | `from sklearn.pipeline import make_pipeline`<br/>`pipe = make_pipeline(StandardScaler(), LogisticRegression())`                                                                                                                                                                |
| `ColumnTransformer`        | `ColumnTransformer(transformers, remainder='drop', sparse_threshold=0.3, n_jobs=None, verbose_feature_names_out=True)` — Different preprocessors per column group. | `from sklearn.compose import ColumnTransformer`<br/>`ct = ColumnTransformer([`<br/>` ("num", StandardScaler(), ["age", "income"]),`<br/>` ("cat", OneHotEncoder(handle_unknown="ignore"), ["country", "device"])`<br/>`])`                                                     |
| Full preprocessing + model | Combine `ColumnTransformer` with a model in a `Pipeline`.                                                                                                          | `pipe = Pipeline([("prep", ct), ("clf", RandomForestClassifier())])`<br/>`pipe.fit(X_train, y_train)`                                                                                                                                                                          |
| Access named step          | `pipe.named_steps[name]` — Inspect a fitted component.                                                                                                             | `pipe.named_steps["clf"].feature_importances_`                                                                                                                                                                                                                                 |
| `FeatureUnion`             | `FeatureUnion(transformer_list, n_jobs=None, transformer_weights=None)` — Concatenate multiple feature-engineering outputs.                                        | `from sklearn.pipeline import FeatureUnion`<br/>`fu = FeatureUnion([("tfidf", TfidfVectorizer()), ("counts", CountVectorizer())])`                                                                                                                                             |

| Method                | Description                                                                                                                                                  | Code example                                                                                                                                                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cross_val_score()`   | `cross_val_score(estimator, X, y=None, scoring=None, cv=None, n_jobs=None)` — Quick K-fold CV score.                                                         | `from sklearn.model_selection import cross_val_score`<br/>`scores = cross_val_score(pipe, X, y, cv=5, scoring="f1_macro", n_jobs=-1)`<br/>`print(scores.mean(), scores.std())`                                                                                            |
| `cross_validate()`    | `cross_validate(estimator, X, y=None, scoring=None, cv=None, return_train_score=False, return_estimator=False, n_jobs=None)` — Multiple metrics + fit times. | `from sklearn.model_selection import cross_validate`<br/>`out = cross_validate(pipe, X, y, cv=5, scoring=["accuracy", "f1_macro"], return_train_score=True)`                                                                                                              |
| `GridSearchCV`        | `GridSearchCV(estimator, param_grid, scoring=None, cv=None, refit=True, n_jobs=None, verbose=0)` — Exhaustive search.                                        | `from sklearn.model_selection import GridSearchCV`<br/>`param_grid = {"clf__n_estimators": [100, 300], "clf__max_depth": [None, 10, 20]}`<br/>`gs = GridSearchCV(pipe, param_grid, cv=5, scoring="accuracy", n_jobs=-1)`<br/>`gs.fit(X, y)`                               |
| `RandomizedSearchCV`  | `RandomizedSearchCV(estimator, param_distributions, n_iter=10, scoring=None, cv=None, random_state=None, n_jobs=None)` — Random sampling.                    | `from sklearn.model_selection import RandomizedSearchCV`<br/>`from scipy.stats import uniform, randint`<br/>`param_dist = {"clf__C": uniform(0.01, 10), "clf__max_iter": randint(100, 1000)}`<br/>`rs = RandomizedSearchCV(pipe, param_dist, n_iter=50, cv=5, n_jobs=-1)` |
| `HalvingGridSearchCV` | `HalvingGridSearchCV(estimator, param_grid, factor=3, resource='n_samples', scoring=None, cv=5, n_jobs=None)` — Tournament-style. | Inspect best model    | Attributes `best_params_`, `best_score_`, `best_estimator_` after fitting.                                                                                   | `print(gs.best_params_, gs.best_score_)`<br/>`best_model = gs.best_estimator_`                                                                                                                                                                                            |
| `validation_curve()`  | `validation_curve(estimator, X, y, param_name, param_range, scoring=None, cv=None, n_jobs=None)` — Score vs one hyperparameter.                              | `from sklearn.model_selection import validation_curve`<br/>`train, val = validation_curve(model, X, y, param_name="max_depth", param_range=[1, 3, 5, 10, 20], cv=5)`                                                                                                      |
| `learning_curve()`    | `learning_curve(estimator, X, y, train_sizes=np.linspace(0.1, 1.0, 5), cv=None, scoring=None, n_jobs=None)` — Score vs training size.                        | `from sklearn.model_selection import learning_curve`<br/>`sizes, train_s, val_s = learning_curve(model, X, y, train_sizes=np.linspace(0.1, 1.0, 5), cv=5)`                                                                                                                |

## Metrics

| Metric                                          | Use case                                                                                                                                    | Code example                                                                                                                         |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `accuracy_score`                                | `accuracy_score(y_true, y_pred, normalize=True, sample_weight=None)` — Overall correctness. Misleading on imbalanced data.                  | `from sklearn.metrics import accuracy_score`<br/>`accuracy_score(y_true, y_pred)`                                                    |
| `precision_score` / `recall_score` / `f1_score` | `f1_score(y_true, y_pred, average='binary', sample_weight=None, zero_division=0)` — `average`: `'macro'`, `'weighted'`, `'micro'`, `None`.  | `from sklearn.metrics import f1_score`<br/>`f1_score(y_true, y_pred, average="macro")`                                               |
| `roc_auc_score`                                 | `roc_auc_score(y_true, y_score, average='macro', multi_class='raise', sample_weight=None)` — Pass `y_proba`, not `y_pred`.                  | `from sklearn.metrics import roc_auc_score`<br/>`roc_auc_score(y_true, y_proba)`                                                     |
| `average_precision_score`                       | `average_precision_score(y_true, y_score, average='macro', sample_weight=None)` — Area under PR curve. Better for imbalanced data.          | `from sklearn.metrics import average_precision_score`<br/>`average_precision_score(y_true, y_proba)`                                 |
| `log_loss`                                      | `log_loss(y_true, y_pred, normalize=True, sample_weight=None, labels=None)` — Cross-entropy.                                                | `from sklearn.metrics import log_loss`<br/>`log_loss(y_true, y_proba)`                                                               |
| `confusion_matrix`                              | `confusion_matrix(y_true, y_pred, labels=None, sample_weight=None, normalize=None)` — Raw counts of true vs predicted.                      | `from sklearn.metrics import confusion_matrix`<br/>`confusion_matrix(y_true, y_pred, labels=[0, 1, 2])`                              |
| `classification_report`                         | `classification_report(y_true, y_pred, labels=None, target_names=None, digits=2, output_dict=False)` — Per-class + macro/weighted averages. | `from sklearn.metrics import classification_report`<br/>`print(classification_report(y_true, y_pred, target_names=labels))`          |
| `mean_squared_error` / `mean_absolute_error`    | `mean_squared_error(y_true, y_pred, sample_weight=None, squared=True)` — `squared=False` returns RMSE.                                      | `from sklearn.metrics import mean_squared_error, mean_absolute_error`<br/>`mean_squared_error(y_true, y_pred, squared=False) # RMSE` |
| `r2_score`                                      | `r2_score(y_true, y_pred, sample_weight=None, multioutput='uniform_average')` — 1.0 perfect; can be negative.                               | `from sklearn.metrics import r2_score`<br/>`r2_score(y_true, y_pred)`                                                                |
| `silhouette_score`                              | `silhouette_score(X, labels, metric='euclidean', sample_size=None, random_state=None)` — Cluster quality without ground truth.              | `from sklearn.metrics import silhouette_score`<br/>`silhouette_score(X, labels)`                                                     |
| Custom scorer                                   | `make_scorer(score_func, greater_is_better=True, needs_proba=False, needs_threshold=False)` — Wrap a custom function.                       | `from sklearn.metrics import make_scorer`<br/>`scorer = make_scorer(custom_fn, greater_is_better=True)`                              |

## Industry-standard scikit-learn ML systems

| Method | Method description | Code example |
|---|---|---|
| End-to-end pipeline artifact | Persist preprocessing and model together; never save only the estimator. | `pipe = Pipeline([("prep", preprocessor), ("model", HistGradientBoostingClassifier())])`<br/>`pipe.fit(X_train, y_train)`<br/>`joblib.dump(pipe, "churn_pipeline.joblib")` |
| ColumnTransformer contract | Encode numeric/categorical handling explicitly by column list. | `prep = ColumnTransformer([("num", StandardScaler(), num_cols), ("cat", OneHotEncoder(handle_unknown="ignore"), cat_cols)], remainder="drop")` |
| Leakage-safe CV | Put all preprocessing inside the pipeline so each fold fits transformers only on train fold. | `scores = cross_val_score(pipe, X, y, cv=StratifiedKFold(5, shuffle=True, random_state=42), scoring="roc_auc")` |
| Grouped CV | Split by user/customer/account to avoid identity leakage. | `cv = GroupKFold(n_splits=5)`<br/>`scores = cross_val_score(pipe, X, y, groups=user_ids, cv=cv, scoring="f1_macro")` |
| Time-series CV | Preserve temporal ordering for forecasting or time-dependent labels. | `cv = TimeSeriesSplit(n_splits=5)`<br/>`scores = cross_val_score(pipe, X.sort_values("date"), y_sorted, cv=cv)` |
| Baseline first | Establish simple baselines before complex models. | `dummy = DummyClassifier(strategy="most_frequent")`<br/>`dummy.fit(X_train, y_train)`<br/>`baseline = balanced_accuracy_score(y_test, dummy.predict(X_test))` |
| Threshold tuning | Tune decision threshold separately from model fitting. | `proba = pipe.predict_proba(X_valid)[:, 1]`<br/>`best_t = max(np.linspace(0, 1, 101), key=lambda t: f1_score(y_valid, proba >= t))` |
| Probability calibration | Calibrate when probabilities drive decisions. | `cal = CalibratedClassifierCV(pipe, method="isotonic", cv=5)`<br/>`cal.fit(X_train, y_train)` |
| Slice evaluation | Measure performance across important segments, not only global metrics. | `for segment, idx in X_test.groupby("country").groups.items():`<br/>`    print(segment, roc_auc_score(y_test.loc[idx], proba[idx]))` |
| Feature importance caution | Use permutation importance on holdout data; impurity importances can mislead. | `result = permutation_importance(pipe, X_test, y_test, scoring="roc_auc", n_repeats=10, random_state=42)` |
| Model card | Record intended use, data, metrics, limitations, and owners. | `model_card = {"model": "churn-v3", "auc": auc, "owner": "growth-ml", "limitations": ["not for new markets"]}` |
| Reproducible training | Pin random states and log library versions. | `params = {"random_state": 42}`<br/>`mlflow.log_params({"sklearn": sklearn.__version__, "seed": 42})` |
| Schema validation at inference | Reject requests with missing or extra columns before prediction. | `expected = list(pipe.feature_names_in_)`<br/>`if list(input_df.columns) != expected:`<br/>`    raise ValueError("schema mismatch")` |

| Imbalance strategy | Compare class weights, resampling, thresholding, and metric choice. | `clf = LogisticRegression(class_weight="balanced", max_iter=1000)` |
