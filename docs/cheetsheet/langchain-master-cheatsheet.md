# LangChain Master Cheatsheet

LangChain (and its successor LangGraph) is the dominant framework for building
LLM applications: chat agents, RAG pipelines, tool-using agents, and
structured-output systems. Covers the modern `langchain_core` + LCEL (LangChain
Expression Language) API as of late 2024 / early 2025.

## Installation and setup

| Method                | Description                                                                                                                     | Code example                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Install core          | `pip install langchain langchain-core langchain-community` — Core abstractions + community integrations.                        | `pip install langchain langchain-openai langchain-anthropic`                                    |
| Provider packages     | `pip install langchain-openai langchain-anthropic langchain-google-genai langchain-huggingface` — One package per LLM provider. | `pip install langchain-openai`                                                                  |
| RAG/embeddings extras | `pip install langchain-chroma faiss-cpu pypdf tiktoken sentence-transformers`.                                                  | `pip install langchain-chroma faiss-cpu pypdf`                                                  |
| API keys              | Set via env vars: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, etc. Or pass `api_key=` to model constructor.                          | `import os`<br/>`os.environ["OPENAI_API_KEY"] = "sk-..."`                                       |
| LangSmith tracing     | `LANGCHAIN_TRACING_V2=true` + `LANGCHAIN_API_KEY=...` — Enables observability.                                                  | `os.environ["LANGCHAIN_TRACING_V2"] = "true"`<br/>`os.environ["LANGCHAIN_API_KEY"] = "ls__..."` |

## LCEL: chaining with pipes

| Method                 | Description                                                                                                                     | Code example                                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| LCEL pipe operator   | Pipe one runnable into another. Output of left becomes input of right.                                                          | `chain = prompt.pipe(llm).pipe(StrOutputParser())`<br/>`print(chain.invoke({"topic": "cats"}))`                                                                                                                                         |
| `StrOutputParser`      | `StrOutputParser()` — Extracts the string `.content` from an `AIMessage`.                                                       | `from langchain_core.output_parsers import StrOutputParser`<br/>`chain = prompt.pipe(llm).pipe(StrOutputParser())`                                                                                                                      |
| `PydanticOutputParser` | `PydanticOutputParser(pydantic_object=Model)` — Parses LLM JSON output into a Pydantic model.                                   | `from langchain_core.output_parsers import PydanticOutputParser`<br/>`from pydantic import BaseModel`<br/>`class Person(BaseModel):`<br/>` name: str`<br/>` age: int`<br/>`parser = PydanticOutputParser(pydantic_object=Person)` |
| `JsonOutputParser`     | `JsonOutputParser(pydantic_object=None)` — Parses any JSON output. Streaming-friendly.                                          | `from langchain_core.output_parsers import JsonOutputParser`<br/>`chain = prompt.pipe(llm).pipe(JsonOutputParser())`                                                                                                                    |
| `RunnableParallel`     | `RunnableParallel(name1=runnable1, name2=runnable2)` or `{...}` dict — Run multiple in parallel; output is a dict.              | `from langchain_core.runnables import RunnableParallel`<br/>`para = RunnableParallel(joke=joke_chain, fact=fact_chain)`<br/>`print(para.invoke({"topic": "octopus"}))`                                                            |
| `RunnablePassthrough`  | `RunnablePassthrough()` — Forwards input unchanged. Useful inside runnable maps for passing original input alongside transforms.        | `from langchain_core.runnables import RunnableParallel, RunnablePassthrough`<br/>`chain = RunnableParallel(context=retriever, question=RunnablePassthrough()).pipe(prompt).pipe(llm)`                                                                               |
| `RunnableLambda`       | `RunnableLambda(func)` — Wrap any Python function as a runnable.                                                                | `from langchain_core.runnables import RunnableLambda`<br/>`upper = RunnableLambda(lambda x: x.upper())`                                                                                                                           |
| `.with_config()`       | `runnable.with_config(config)` — Set tags, metadata, callbacks for tracing.                                                     | `chain.with_config({"tags": ["prod", "v1"]})`                                                                                                                                                                                     |
| `.with_retry()`        | `runnable.with_retry(retry_if_exception_type=..., wait_exponential_jitter=True, stop_after_attempt=3)` — Auto-retry on failure. | `safe_llm = llm.with_retry(stop_after_attempt=3)`                                                                                                                                                                                 |
| `.with_fallbacks()`    | `runnable.with_fallbacks(fallbacks)` — Try alternates if primary fails.                                                         | `robust = primary_llm.with_fallbacks([backup_llm])`                                                                                                                                                                               |

| Method                      | Description                                                                                                                                 | Code example                                                                                                                                                                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## RAG pipeline (LCEL)

| Method             | Description                                                                        | Code example                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Basic RAG chain    | Pipe retriever output into a prompt, then LLM, then parser.                        | `from langchain_core.runnables import RunnableParallel, RunnablePassthrough`<br/>`from langchain_core.output_parsers import StrOutputParser`<br/>`prompt = ChatPromptTemplate.from_template("""Answer using only the context.`<br/><br/>`Context: {context}`<br/><br/>`Question: {question}""")`<br/>`def format_docs(docs):`<br/>` return "\n\n".join(d.page_content for d in docs)`<br/>`context_chain = retriever.pipe(format_docs)`<br/>`rag = RunnableParallel(context=context_chain, question=RunnablePassthrough()).pipe(prompt).pipe(llm).pipe(StrOutputParser())`<br/>`print(rag.invoke("What is RAG?"))` |
| Cite sources       | Return `dict` with both answer and source documents.                               | `answer_chain = prompt.pipe(llm).pipe(StrOutputParser())`<br/>`chain = RunnableParallel(context=retriever, question=RunnablePassthrough()).assign(answer=answer_chain)`                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Conversational RAG | Maintain chat history; rephrase follow-ups as standalone queries before retrieval. | `condense_prompt = ChatPromptTemplate.from_template("Given history {history} and question {q}, output a standalone query.")`<br/>`# then pipe rephrased into retriever, then into RAG chain`                                                                                                                                                                                                                                                                                                                                                                                 |

## Common patterns

| Pattern                              | Code                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Simple Q&A chain                     | `prompt = ChatPromptTemplate.from_messages([("system", "Be concise."), ("human", "{question}")])`<br/>`chain = prompt.pipe(llm).pipe(StrOutputParser())`<br/>`print(chain.invoke({"question": "Why is the sky blue?"}))`                                                                                                                                   |
| Streaming response                   | `for chunk in chain.stream({"question": "Tell me a story"}):`<br/>` print(chunk, end="", flush=True)`                                                                                                                                                                                                                                                |
| Batched calls                        | `chain.batch([{"question": q} for q in questions], config={"max_concurrency": 5})`                                                                                                                                                                                                                                                                   |
