# Security handbook

## Passwords and MFA
Use the company password manager. Multi-factor authentication is mandatory on email, the VPN and every production console. Hardware keys are issued on request.

## Reporting incidents
Report a suspected phishing email or lost laptop to security@ within one hour, even outside working hours. The on-call security engineer responds within 30 minutes.

## Data classification
Customer data is Confidential. It may not be pasted into external AI tools, personal email or public issue trackers. Internal design documents are Internal.

## Laptops
Laptops must use full-disk encryption and lock after five minutes idle. Never leave a laptop unattended in a car.
