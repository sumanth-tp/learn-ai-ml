# On-call runbook

## Rota
Engineers rotate weekly, Monday 10:00 to Monday 10:00. Swaps are agreed in the on-call channel and recorded in the calendar.

## Paging
A page must be acknowledged within 5 minutes. If nobody acknowledges within 15 minutes it escalates to the secondary, then to the engineering manager.

## Severity levels
SEV1 means customers cannot use the product; open an incident channel and page the incident commander. SEV2 means degraded service for some customers. SEV3 is everything else and waits for working hours.

## After an incident
Write a blameless post-incident review within five working days for every SEV1 and SEV2.
